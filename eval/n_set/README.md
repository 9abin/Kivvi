# N 평가셋 (독립 생성 질문 80개)

용어집 끔/켬 효과를 개발에 쓰지 않은 질문으로 보기 위한 평가셋이다. N001~N010은 먼저 만든 10개, N011~N080은 규정을 보지 않은 작성자가 만든 70개다.
gold는 시스템 답변을 보기 전에 규정 원문에서 작성해 고정했다.

| 파일 | 내용 |
|---|---|
| `n_gold_80_v5_1.jsonl` | 질문 80개와 gold. 핵심 / 언급시검사 / 보충, 핵심근거 / 보충근거 / 적용배제근거, 금지내용, 필수 하위질문, 확정후보 62건·미확정 18건 구분 |
| `scoring_rules_v5_1.md` | 채점 규칙(등급, 집계, 추가 실행, 사람 확인 범위) |
| `freeze_manifest.json` | 고정한 gold와 규칙의 SHA-256 |
| `run_n_set.py` | 80문항을 홀수 번호는 끔→켬, 짝수 번호는 켬→끔으로 실행. 실행 전 코드·DB·프롬프트·모델·gold·규칙 해시를 run_manifest.json에 저장 |
| `check_n_set_run.py` | 실행 기록의 구조 검증(160건, 교차 순서, 설정 차이는 용어집뿐 등) |

```
python eval/n_set/run_n_set.py --outdir <기록 폴더> --dry-run     # API·모델 호출 없이 구조만 확인
python eval/n_set/check_n_set_run.py <기록 폴더>
python eval/n_set/run_n_set.py --outdir <기록 폴더>               # 실제 실행: 답변 160회, OpenAI API 호출
```

- gold나 규칙을 바꾸면 해당 문항은 개발용으로 표시한다. 답변을 본 뒤 기준을 바꾸지 않는다.
- 실제 실행은 비용이 들므로 실행 전에 확인을 받는다.
- 이미 실행한 N001~N010 예비 실행 답변은 전체 실행의 초회 답과 섞지 않는다.
