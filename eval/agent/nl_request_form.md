# 개정 요청 작성 양식 (에이전트 평가 ③)

**목적:** 개정문을 자연어로 요청했을 때 에이전트가 요청대로 쓰는지 평가한다. 에이전트를 만든 사람이 요청을 쓰면 에이전트가 잘 읽는 말투로 쓰게 되므로, **에이전트를 모르는 분**이 평소처럼 적어 주세요.

## 쓰는 법
- 회사 내부규정 90개 중 아무 규정이나 골라, 담당자에게 말하듯이 한 문장으로 요청을 적어 주세요. **15~20개**
- 어느 규정의 어느 조(필요하면 항)를 어떻게 바꾸라는 것인지 알 수 있게 적어 주세요.
- 규정 원문은 ALIO 공시본을 보면 됩니다. 이 도구의 화면(규정 도우미)에서 조문을 열어 봐도 됩니다.
- **요청을 쓴 뒤 고치지 마세요.** 이상한 말투도 그대로 평가에 씁니다.

## 이런 유형을 골고루 섞어 주세요 (한 유형에 2~4개)
| 유형 | 예 (이 예시는 평가에서 뺍니다) |
|---|---|
| 숫자·기간 바꾸기 | 「여비규정 국내 출장 일비를 올려줘」 |
| 조 삭제 | 「문서관리규정에서 〇〇 조항은 없애자」 |
| 조 신설 | 「징계지침에 〇〇 상황을 다루는 조항을 새로 넣어줘」 |
| 번호 이동·끼워 넣기 | 「제〇조 앞에 새 조문을 하나 끼워 넣고 싶다」 |
| 용어·명칭 바꾸기 | 「〇〇라는 말을 전부 〇〇로 바꿔」 |
| 법령 개정 반영 | 「〇〇법이 바뀌었다는데 맞춰서 고쳐줘」 |
| **함정** | 같은 낱말이 다른 낱말 속에 들어 있는 경우(예: 「상임이사」를 바꾸면 「비상임이사」도 바뀌면 안 됨), 요청이 모호하거나 틀린 경우, 규정에 없는 조를 가리키는 경우 |
