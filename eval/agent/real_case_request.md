# 규정 개정 때 놓친 사례 요청 (내규 담당 부서·팀원용)

규정 도우미가 「한 규정을 고칠 때 다른 곳에서 함께 봐야 하는 곳」을 얼마나 찾는지 실제 사례로 확인하려 합니다.
5~10건이면 충분합니다. 기억나는 범위에서 짧게 적어 주세요. 정확한 조 번호를 몰라도 됩니다.

| 항목 | 적을 내용 | 예시 |
|---|---|---|
| 1. 고친 규정 | 규정 이름과 대략의 조항 | 취업규칙, 출산 관련 휴가 조항 |
| 2. 무엇을 바꿨나 | 한 줄 | 유산·사산 휴가 일수를 늘림 |
| 3. 함께 봤어야 하는 곳 | 다른 규정·조항 | 복무규정의 출산전후휴가 조항 |
| 4. 어떻게 알게 됐나 | 감사 지적, 직원 문의, 나중에 발견 등 | 직원 문의로 두 규정 일수가 다른 것을 앎 |
| 5. 둘이 어떻게 이어져 있었나 | 해당하는 것 고르기: ① 조문을 직접 인용 ② 같은 용어 ③ 같은 주제지만 말이 다름 ④ 제도·절차가 이어짐 ⑤ 모르겠음 | ③ |

- 개인정보·내부 사건 내용은 빼고 적어 주세요. 규정 이름과 조항 수준이면 충분합니다.
- 받은 사례는 시스템을 고치는 데 쓰지 않고, 시스템이 찾는지 확인하는 평가에만 씁니다 (평가가 부풀지 않도록).
- 5번의 분류로 「인용으로 이어진 문제」와 「인용 없이 이어진 문제」를 나눠, 각각 얼마나 찾는지 따로 보고합니다.
