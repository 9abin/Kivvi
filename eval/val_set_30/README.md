# val셋 30건 (개발용) - 사람 검토 전 AI 초안

- 형식은 PR #11 평가셋과 같다: `산출/changes.jsonl`(개정), `산출/labels_final.jsonl`(영향 조, 근거 문장은 원문 발췌). `python validate.py labels 산출/labels_final.jsonl 산출/changes.jsonl` 통과.
- 사람이 검토하기 전의 AI 초안이다. 개정문 작성(A)은 서브에이전트 3개(문체 쏠림 방지), 라벨(B1, B2)은 서로 못 보는 격리 폴더에서 구간별로, 불일치 결정(C)은 B1/B2 산출물만 보고 했다. A는 후보 찾기 코드, 평가 결과, 그래프를 보지 않았다.
- 조 뽑기: `kit_sample.py`(시드 20261110). 도메인 8건(도메인 DB에서 정의/근거로 연결된 조), 그 밖 22건(전체 규정, 도메인 후보 조 제외), 규정별 최대 2건. 제외 목록은 `excluded_articles.json`(PR11 I01~I24, r2, r3, 징계층, PR12 120문항, 기존 4도메인 30건).
- 1차 결과 분포가 목표 모양에서 어긋나(0개 43%, 3개 이상 큰 구간 없음) 8건을 `kit_replace.py`(시드 20261111)로 교체했다. 1차 기록은 `*_round1.*`, 교체 전 조는 `replaced_round1.json`.
- `used_articles.json`: 이 val셋이 쓴 개정 조(최종 100건 제외 목록에 추가용).
- 도구: `지시서.md`(val셋용 문구만 수정), `validate.py`(원본 그대로).
- V03은 사람 검토에서 개정문이 부자연스럽다고 판단해 한 번 더 교체했다(임직원행동강령 제1조, 시드 20261112). 교체 전 기록은 `산출/*_round2.jsonl`.
