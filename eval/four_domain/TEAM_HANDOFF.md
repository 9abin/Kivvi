# 휴직 원본 보존 및 인사·보수·휴가 그래프 확장 — 팀 공유

**현재 평가 문항은 [한 문항·한 곳 변경 60문항](single_change/README.md)으로 수정했다.** 모든 개정 연산은 한 곳만 수정하며 종합 문항은 제외한다. 모델 평가 실행 전이므로 아래 120문항 점수를 새 구성의 결과로 사용하지 않는다. 아래 내용은 기존 실험 기록이다.

## 무엇을 만든 것인가

사용자가 작성한 휴직 온톨로지를 기반으로 인사·보수·휴가를 확장한 통합 실험본이다.

- 휴직: 사용자 원본의 6개 개념, 연결 151개, 속성 설명 38개, 대표 근거 7개, 상위 항 연결 38개, 수정 이력 46개를 그대로 보존했다.
- 인사·보수·휴가: 원문 기반 AI 재검토 연결 1,846개를 추가했다. 사람 검수 완료본은 아니다.
- 기존 DB 테이블을 보존하고 근거·값·조건·출처 및 검토 상태를 위한 보조 테이블을 추가했다.
- 탐색·평가 코드는 별도로 구현했다. 통합 평가 점수가 사용자 휴직 스키마 자체의 정확도는 아니다.

이전 자동 확장본은 휴직 원본을 실제로 보존하지 않았다. 원본 연결 67개가 빠졌으며 64개는 휴직 공통 연결이었다. 원본 파일은 손상되지 않았다. 이번 복원본은 모든 원본 테이블을 행 단위로 대조해 기존 행이 바뀌지 않았음을 확인했다.

## 평가 결과

전체 90개 문서에서 검색하고, 고정된 120문항을 같은 OpenAI Luna·최종 후보 10개·공통 판정 프롬프트로 비교했다. 실제 개정 연산을 적용한 전후 원문으로 판단한다.

| 방식 | 기존 지시 · 전체 120문항 | 전후 비교 수정 지시 · 전체 120문항 |
|---|---:|---:|
| RAG | 77/120 | 83/120 · 69.2% |
| PR #11 그래프 + RAG | 80/120 · 검토 대기 1문항 | 78/120 · 검토 대기 3문항 |
| 복원·재검토 도메인 그래프 + RAG | 88/120 | 93/120 · 77.5% |

수정 지시는 개정 전후의 문제 유무를 각각 확인하도록 명확히 했으며, 세 방식에 똑같이 적용했다. DB·검색 후보·모델·정답·채점기는 고정했다. 도메인 그래프 방식은 6문항 개선·1문항 퇴행으로 순증 5문항이다. 같은 수정 지시의 RAG 대비 차이는 **8.33%p**이며 10%p 향상을 달성했다고 해석하지 않는다.

기존 실패 사례를 보고 수정한 같은 개발 집합의 단회 재평가다. 미사용 문항에서의 일반화 성능은 확인하지 않았다. [새 결과와 재현 기록](results/state-compare-v2/README.md), [실험 계획·실행 방법](STATE_COMPARE_EXPERIMENT.md)을 참고한다. 기존 결과는 `results/reviewed/`에 그대로 보존했다.

기존 지시의 RAG·PR 대조군 240개 기록은 이전 실행과 문맥·순위·응답이 같은지 확인하고 동일 요청 캐시를 재사용했다. 이전 자동 도메인 그래프는 86/120이었다. 이번 변경에는 원본 복원, 다른 세 범주 재검토, 개념별 속성 매칭과 공통 상하위 탐색 수정이 함께 들어갔다. 이 차이를 휴직 복원만의 효과로 분리할 수 없다.

문항 성공은 알려진 정답 문제를 모두 찾았을 때 인정한다. 정답은 사람 검수 전 AI 초안이며, 120문항은 20개 관계를 변형·조합한 것이다. 독립적인 120개 관계의 일반화 성능이나 온톨로지 자체의 정밀도·재현율을 측정한 것은 아니다.

## 실제 문제 예시 — 읽기 쉽게 줄인 표현

실제 모델에는 비교 상대나 오류 개수를 알려주지 않는다. 아래 정답 설명은 팀 검토용으로 붙였다. 모두 가상 개정이다.

문제 유형은 개정 전후 **검사 대상 관계**의 변화로 구분한다.

| 문제 유형 | 개정 전 → 개정 후 | 문항 수 |
|---|---|---:|
| 새 문제 발생 | 없던 불일치·깨진 인용이 생김 | 40 |
| 정상 변경 | 전후 모두 해당 문제가 없음 | 40 |
| 기존 문제 해소 | 있던 불일치·깨진 인용이 없어짐 | 40 |

개별 60문항은 한 가지 규칙 변경 묶음을 검사한다. 종합 60문항은 인사·보수·휴가·휴직의 서로 다른 변경 4묶음을 한 개정안에 넣는다. 각 집합은 위 세 유형을 20개씩 포함한다. 범주별 결과는 개별 60문항을 주된 주제에 따라 인사·보수·휴가·휴직 15개씩 나눈 것으로, 추가 문제 집합이 아니다. 변경과 무관하게 유지되는 기존 문제는 보고 대상에서 제외한다.

### 새 문제 발생: Q015 중 보수 변경 부분

인사규정 제28조의 업무 외 질병 휴직 기본급만 **1/2 → 2/3**으로 바꾸고, 급여규정 제16조는 **1/2**로 둔다.

**기대 정답:** 이전에는 1/2로 일치했지만 변경 후 2/3 대 1/2가 되어 새 지급률 불일치가 생겼다. Q015 전체에는 다른 범주의 변경도 포함된다.

### Q029: 기존 문제 해소

**가상 개정 전 상태:** 가족돌봄휴직의 1회 최소 사용기간이 인사규정 제31조에서는 15일, 취업규칙 제46조에서는 30일이다.

**질문:** 취업규칙 제46조의 ‘30일 이상’을 ‘15일 이상’으로 바꾼다. 이번 개정으로 새로 생긴 불일치·깨진 인용과 해소된 기존 문제를 찾아라.

**기대 정답:** 15일/30일의 기존 불일치가 15일/15일로 일치하여 해소됐다.

이번 복원 그래프 실행에서는 상대 조항과 전후 근거를 모두 찾았지만 Luna가 해소 문제를 출력하지 않았다. 검색과 판정을 나눠 볼 필요가 있는 사례다.

### Q022: 문제 없는 변경

**질문:** 1년간 80% 이상 출근한 직원의 연차 기본일수를 다음 세 곳에서 모두 15일에서 16일로 바꾼다.

1. 복무규정 제21조 제1항 제1호.
2. 취업규칙 별지 제1호 근로계약서.
3. 취업규칙 별지 제2호 근로계약서.

이번 개정으로 새로 생긴 불일치·깨진 인용과 해소된 기존 문제를 찾아라.

**기대 정답:** 해당 관계는 전후 모두 일치한다. 새 문제·해소 문제 없음. 외부 법령 적법성 평가는 이 시험의 범위 밖이다.

### Q015: 네 범주 종합 변경

**질문:** 다음 개정안을 실제 적용하고 새 문제·해소 문제를 모두 찾아라.

1. 인사규정 제34조 직위해제 조문을 제83조로 이동한다. 내용은 유지하고 옛 번호는 비운다.
2. 인사규정 제28조의 업무 외 질병 휴직 기본급을 1/2에서 2/3으로 바꾼다.
3. 복무규정 제30조의 일반 출산 후 최소 휴가기간을 45일에서 50일로 바꾼다.
4. 가족돌봄휴직 연간 상한은 인사규정 제31조와 취업규칙 제46조를 모두 90일에서 120일로 바꾼다.

**기대 정답:**

- 성과급 지급지침 제2조, 인사규정 제39조, 급여규정 제17조에 남은 제34조 인용이 깨진다. 조항 쌍 기준 3건이다.
- 급여규정 제16조에 남은 업무 외 질병 휴직 기본급 1/2과 인사규정의 2/3이 어긋난다.
- 취업규칙 제39조에 남은 출산 후 최소기간 45일과 복무규정의 50일이 어긋난다.
- 가족돌봄휴직 상한은 양쪽을 함께 120일로 바꿨으므로 새 문제가 아니다.

종합 문항은 일괄 개정에서 여러 관계를 점검하는 시험이다. 네 범주가 반드시 하나의 인과 사슬로 이어지는 다단계 추론 문제라는 뜻은 아니다.

## 저장소 실행

실행 명령과 자료 위치는 [README](README.md)를 참고한다. DB를 읽는 실제 탐색기는 `validated_graph.py`이며, 사용자 휴직 간선을 정규식으로 다시 만들지 않는다. 현재 폴더 기준의 상대 경로를 사용하고 결과 재채점은 API 없이 실행할 수 있다.
