# 전체 평가 결과

| 방식 | 전체 120문항 결과 |
|---|---:|
| RAG | 77/120 · 64.2% |
| PR #11 그래프 + RAG | 80/120 · 추가 발견 1문항 검토 대기 |
| 복원·재검토 도메인 그래프 + RAG | 88/120 · 73.3% |

문항 성공은 그 문항의 알려진 새 문제·해소 문제를 모두 맞혔을 때 인정한다. 정답은 사람 검수 전 AI 초안이다. 정답 목록 밖 발견은 자동 오탐 처리하지 않고 검토 대기로 둔다.

기록된 360개 방식별 응답을 오프라인으로 재채점할 수 있다. `python eval/four_domain/replay_results.py`를 실행하면 `runs/replay/`에 결과를 만든다. 전체 입력이 같은 RAG·PR 대조군 240개는 이전 결과와 문맥·순위·응답이 일치함을 확인하고 캐시를 재사용했다.
