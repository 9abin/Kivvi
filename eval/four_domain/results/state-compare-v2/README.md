# 전후 상태 비교 지시 수정: 전체 결과

| 방식 | 기존 지시 | 수정 지시 |
|---|---:|---:|
| RAG | 77/120 | 83/120 |
| PR 그래프 + RAG | 80/120 | 78/120 · 추가 발견 3문항 검토 대기 |
| 복원·재검토 도메인 그래프 + RAG | 88/120 | 93/120 |

도메인 그래프 방식은 새로 맞힌 문항 6개, 기존 정답에서 벗어난 문항 1개다. 전체 차이는 +5문항이다.

같은 수정 지시를 적용한 RAG 대비 차이는 8.33%p다.

검색 후보·순서·문맥·DB·모델·정답·채점기는 바꾸지 않았다. 세 방식 모두 동일한 수정 지시로 120문항을 실행했다. 이전 응답과 새 응답 중 문항별로 더 잘 맞는 답을 고르지 않았다.

정답은 사람 검수 전 AI 초안이다. 기존 실패 사례를 보고 지시를 수정했으므로 같은 개발 집합의 재평가이며, 미사용 문제에 대한 성능은 확인하지 않았다. 추가 발견은 정답을 고쳐 점수에 반영하지 않고 검토 대기로 보존한다.

프롬프트와 실행 설정은 `prompt.txt`, `config.json`, 문항별 개선·퇴행은 `comparison-checks.json`에 있다. JSON 형식 오류 재요청은 `format-validation-retries.jsonl`에 원 응답과 함께 기록한다. 내용이 틀렸다는 이유로 재요청하지 않았다.

오프라인 재채점: `python eval/four_domain/replay_results.py --variant state-compare-v2`

검토 예시: Q029는 가족돌봄휴직 최소기간의 15일/30일 → 15일/15일 일치를, Q038은 육아휴직 총기간의 3년/4년 → 4년/4년 일치를 기존 문제 해소로 보고하여 정답이 됐다. 새로 정답이 된 도메인 그래프 6문항의 제공 인용은 모두 표시된 원문과 일치했다.

퇴행 Q080은 출산전후휴가 차액 보전기간이 개정 전부터 양쪽 60일분으로 같다고 설명하면서도 `resolved` 항목으로 출력한 과잉 판정이다. 나머지 해소 문제를 맞혀도 문항 전체는 오답 처리했다. 이 응답을 이전 정답으로 교체하지 않았다.

채점의 정답 판별 단위는 상태·오류 종류·조항 쌍이다. 인용 유효성은 별도 기록하며, 모든 요약 문장의 의미 정확성을 이 점수가 보증하지 않는다.
