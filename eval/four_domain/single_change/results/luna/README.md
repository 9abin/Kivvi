# 단일 변경 60문항 평가 결과

각 문항에서 한 곳만 실제 수정하고 전체 90개 문서에서 비교 후보를 검색했다. 같은 OpenAI Luna(`gpt-5.6-luna`, reasoning `low`)·후보 10개·동일 전후 비교 프롬프트로 세 방식을 평가했다.

| 방식 | 전체 60문항 결과 |
|---|---:|
| RAG | 46/60 · 76.7% |
| PR 그래프 + RAG | 52/60 · 86.7% |
| 복원·재검토 도메인 그래프 + RAG | 53/60 · 88.3% |

정답은 사람 검수 전 AI 초안이다. 문항 성공은 그 문항의 알려진 새 문제·해소 문제를 모두 맞혀야 인정한다. 추가 발견은 검토 대기로 보존하며 정답을 바꿔 점수에 반영하지 않는다.

고정 채점기는 상태·오류 종류·조항 쌍을 대조한다. 원문 인용 유효성은 별도로 기록하며, 이 점수가 모든 요약 문장의 의미 정확성을 보증하지는 않는다. 180개 응답이 모두 완료됐고 JSON 형식 오류 재요청이나 검토 대기 문항은 없었다. 오프라인 재채점 집계는 게시된 집계와 완전히 일치했다.

60문항은 20개 관계의 새 문제·문제 없는 변경·해소 변형이다. **문제 없는 변경 20개는 의미를 유지하는 띄어쓰기 수정 대조군**이며, 실질적 정책 변경의 안전성을 폭넓게 평가한 결과가 아니다. 기존 120문항과 문항 구성·분모가 다르므로 점수를 직접 전후 비교하지 않는다.

`predictions.jsonl`은 전체 180개 응답, `case_results.jsonl`은 문항별 채점 기록, `retrieval.jsonl.gz`는 전후 검색 문맥이다. API 키·개인 환경파일·API 캐시는 포함하지 않는다. `snapshot-hashes.json`으로 기록을 확인하고, API 없이 아래 명령으로 동일 결과를 재채점할 수 있다.

```powershell
python eval/four_domain/single_change/replay_results.py
```
