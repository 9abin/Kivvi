## 한 줄
**내규 개정 요청 하나를 받아, 연쇄로 고칠 곳까지 담은 개정안 패키지(개정문·신·구조문대비표·함께 고칠 조문·법령 대조·확인 질의)를 만들어 오는 에이전트.** 사람은 찾지 않고 고른다.

## 차별점 (공개 제품·연구 조사 범위)
검색·신·구조문대비표·HWPX 출력·외부 규제→사내 정책 매핑은 이미 있다(alio-mcp, 나라이넷, 법령안편집기, CUBE·Regology 등). 우리 것은:
1. 내규 간 **조문 단위 인용**을 원문에서 자동으로 미리 연결 (사람 매핑 아님)
2. 개정안 하나 → 깨짐·해소·확인 필요 → **연쇄 수정안** → 다시 점검 (에이전트 루프)
3. **규칙 기반 적용·검증**: 틀린 개정문은 멈추고 결과는 재현·역추적 (생성형 개정 적용 연구 성공률 63%와 대비)
4. **개정 이력**으로 "상대가 바뀐 뒤 따라가지 않은 곳" 탐지, 법령 조문 변경과 대조
5. 폐쇄망·로컬 (법령은 반입 DB, 초안은 민감 정보라 로컬 LLM)

## 에이전트 구조
```
요청(자연어 또는 개정문) ─▶ [LLM] 개정문 초안 ─▶ [규칙] 적용(사본) ─실패─▶ 오류 메시지로 다시 작성
                                                    │
                                                    ▼
                         [규칙] 변경안 점검: 관련 조항 표·같은 제목·개정 이력·법령 DB
                                                    │ 깨짐 있음
                                                    ▼
                         [규칙] 연쇄 수정 문장 생성(같은 규정: 개정문에 추가 / 다른 규정: 함께 개정안 또는 부칙 관계 조항)
                                                    │ 깨짐 0 또는 더 못 고침
                                                    ▼
                         패키지: 개정문 · 대비표 · 함께 고칠 조문 · 법령 대조 · 판단 필요 질의서 ─▶ 사람이 수락·거절
```
- LLM은 **문안 작성만**(요청 → 개정문, 질의서 문장). 적용·점검·검증은 규칙. LLM이 틀려도 적용 단계에서 멈추거나 점검에서 깨짐으로 잡힌다
- 법적 판단·충돌 판정 안 함, 원문 자동 반영 안 함 ([작업 규칙 §3](05-working-agreement.md))

## 범위
- 포함: 개정 패키지 에이전트, 변경안 점검, 법령 개정 대조, 기준선 점검(설치 때), 검토 화면
- 다른 담당: 법령 DB 구축·반입(한석희), 챗봇 RAG(김가빈)
- 제외: 원문 자동 수정, 법적 판단, 책임·권한 공백 점검, 오탈자(미정)

## 운영 방식 (기관 도입 시 제안안)
근거: [261006-1414-06](../../reports/261006-1414-06-operation-poc.md). 반입 주기·우선순위·처리 기한은 기관이 정할 사항이며 아래는 가정이다.

| 계기 | 시점 | 에이전트 | 받는 쪽 |
|---|---|---|---|
| 내규안 입안 | 초안·요청 시 (제20조) | 개정 패키지 | 업무담당부서 → 제21조 조정 |
| 법령 반입 | 정기 + 긴급 수동 | 바뀐 법조문 → 영향 조문 대조 요청 | 준법감시인, 업무담당부서 |
| 개정 시행 | 시행일 (제23~24조) | 원문 DB 갱신, 재점검, 해소 이슈 종료 | 내규담당부서 |
| 정기 정비 | 분기·반기 (제25조②) | 전수 점검, 기준선 갱신 | 내규담당부서 |

- 이슈 흐름: 신규 → 검토 → 수락·거절·오탐·판단 불가, 전환마다 검토자·일시·의견 기록 (검토 화면 결정 기록)
- 우선순위: 높음(법령 개정 이동, 근거 소멸, 강한 개정 이력 신호) / 중간(오인용, 법령 대조) / 낮음(명칭, 약한 신호)
- 초기 도입: 표본 보정 → 묶음 정리 → 단계적 배분 → 기준선 고정 ([261006-1414-06](../../reports/261006-1414-06-operation-poc.md))

## 평가
- 정답: 1주차 검토 16, 가빈 정리본 7, **가빈 corrections(독립) 23행 + 정상 확인 10** — [goldset](todo/goldset.md)
- 지표: 유형별 재현율·우선순위 높음 비율, 정상 확인 오탐, 수정 제안 일치, 확인 대기 사람 판정 정밀도
- 변경안 점검: 사람이 쓴 시나리오 5~10개로 분류별 일치 (지금 3개는 내가 쓴 초안)
- 에이전트: 연쇄 수정 후 깨짐 0 도달률, 자연어 요청 → 적용 성공률, 사람 수락률
- 한계 명시: 개선에 쓴 사례는 독립 평가에서 분리
