# 00. 현재 상태

새 세션은 [작업 규칙](05-working-agreement.md) 다음에 이 문서를 읽는다. 작업마다 갱신한다. 40줄 이내, 본문 복제 금지(링크만).

- 마지막 갱신: 261015

## 단계
구현 중. 원문 파싱(90건) → 인용 엣지·구조 검사(1주차 §C 구조 대상 11/11) → 벡터 색인(BGE-m3, 4,467 청크) → 대상 불일치 후보(설명구+reranker, 정답 5/5) → 정답 원장 23/23. 실행 기록(역추적), 1차 결과 페이지 `out/report/index.html`(`scripts/make_report.py`). 개정문 적용·대비표 v0, 변경안 점검 v0(시나리오 S01~S03 대조, 독립 평가 아님). 검토 화면 v0, 법률 DB 연결·법령 개정 대조(필수 ③). PoC 필수 4개 v0 완료, 에이전트 연쇄 수정 루프 v0(규칙). 과거 재현·직제 개편 시연, 자연어 개정문(qwen2.5:7b + 규칙·의도 검사, 7/8).
이 저장소: 조항 수정 에이전트(박형건). 법률 DB는 한석희, 챗봇 RAG는 김가빈. ([작업 규칙 §1](05-working-agreement.md))

- **방향: 개정 요청 → 연쇄 수정까지 담은 개정 패키지를 만들어 오는 에이전트.** 주 사용자 내규담당부서·준법감시인, LLM은 문안만·검증은 규칙 → [261007-1645-24](reports/261007-1645-24-direction-agent.md), [03](03-product-plan.md)

- 기법: TAG+SQL 중심, RAG는 의미 검사, CAG는 수정안·기준선, 그래프는 RDB 엣지로 (제안) → [261006-1152-03](reports/261006-1152-03-rag-cag-tag-graph.md)
