## 4. RAG 파이프라인 (가빈, `src/answer/pipeline.py` `Assistant.ask`)

1. 질문 바꿔쓰기(`Generator.rewrite_query`) + 동의어(`src/search/synonyms.py`)
2. **정확 조회**(`exact.py`): 규정 이름 하나 + 「제N조」 하나면 그 조(항) 직접
3. 벡터 + BM25 → **가중 RRF**(0.7 : 0.3, k=60) → 상위 30개 **재순위**(bge-reranker-v2-m3)
4. 용어집으로 라우팅되지 않은 문서 감점
5. 조립: **형제 항 확장**(3,000자까지), **`cites` 1단계 확장**(최대 5개, 외부 법령은 저장된 본문), 근거 예산 8,000자
6. 표 범위 필터, 용어집 필터
7. 답변 모드: answer / partial / none (재순위 점수 기준)
8. 생성(LLM) → 검증: 숫자 대조, 구분 모순, 문장 근거, 빠진 핵심어, 충돌 확인

LLM: `config.py` `OPENAI_MODEL = "gpt-5.6-luna"`(외부 API, 261013에 gpt-4o-mini에서 변경, 바꿔 쓰기·답변·채점 모두). 폐쇄망 원칙과 다름 → 로컬 모델로 바꿀 수 있게 해야 함 (가빈과 확인). 로컬 모델 기준 검색·답변 수치는 아직 없음

## 5. 청킹

| 단위 | 청크 수 |
|---|---|
| 항 (`23234_제5조_2항`) | 3,605 |
| 조 (항이 하나뿐이거나 없음) | 916 |
| 별표·별지 / 부칙 / 기타 | 195 / 89 / 5 |

- 본문 조 2,030개 중 1,124개가 여러 항. 항 중앙값 87자, 조 중앙값 174자, **가장 긴 조 2,519자**(정보보안관리지침 제48조) → 형제 항 3,000자 안에 모든 조가 들어감
- 방식은 **항으로 찾고 조로 읽기**. 오버랩 불필요 (길이가 아니라 주제 희석이 문제)
- 빈 곳: 「제」 없는 「15조」, 조 두 개, 이어지는 질문(규정 이름 없음)은 정확 조회가 안 되고 일반 검색으로 감. 정의 조처럼 호가 많은 항은 한 벡터에 주제가 섞임. 임베딩에 「규정명 > 제N조(제목)」 머리말 없음(재순위에만 씀)

## 9. 261015 추가 (조항 수정 에이전트)
인용·같은 제목 외에 인용 없이 이어지는 영향을 찾는 경로와 근거 종류 표시가 들어갔다. 상세는 리포트 [43](reports/261015-1500-43-term-impact.md)~[50](reports/261015-2300-50-agent-audit.md).
| 경로 | 근거 종류 | 코드 |

| 의미 이웃(미리 계산, 점수 + 간격)·실시간 의미 유사·같은 내규 신설 중복 | 모델 추정 | `neighbors.py`, `change_check.py` |

| 옮겨 간 곳 찾기 (이동 표시 → reranker) | 문서 명시·모델 추정 | `relocate.py`, `scripts/build_relocate.py` |
