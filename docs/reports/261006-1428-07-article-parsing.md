## 요약
원문 90건을 조문 구조(본문 조·항·호·목, 부칙, 별표, 별지)로 나눠 `out/parsed/{규정ID}.json`으로 저장했다.

90건 전체는 본문 조 2,042개. 번호 이상 4건은 원문 쪽 문제로 보여 확인 후보로 남긴다.

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| HWP 제어 문자를 규격대로 처리 (확장·인라인 컨트롤은 8 WCHAR 건너뜀, 서로게이트 쌍 복원) | 제어 문자만 지우면 컨트롤 ID가 깨진 한자(捤獥, 漠杳 등)로 남음 | 정규식으로 쓰레기 글자 제거 |
| 조문 시작은 「제N조(제목)」 또는 「제N조 삭제 / <삭제 …>」만 인정 | 「제1조에 따라 …」로 시작하는 이어지는 줄이 조문으로 잡히는 것 방지 | 「제N조」로 시작하면 모두 조문 |
| 순서 가정: 머리 → 본문 → 부칙 → 별표·별지. 별표·별지가 시작되면 본문으로 돌아가지 않음 | 계약서형 별지의 「제1조」가 본문 조문을 오염시키지 않게 (02-specs 별지 처리) | 위치 무관 판단 |
| 조문 ID 임시안: `{규정ID}:{조}[의M]`, 항·호·목 `-{항}-{호}-{목}`, 부칙 `{규정ID}:부칙{순번}:{조}`, 별표·별지 `{규정ID}:별표1` | 사람이 읽을 수 있고 1주차 사례 표기와 대응. 규정ID는 ALIO 규정 번호 | 해시 ID |
| 위계: 정관 / 규정(규정·규칙) / 지침(지침·강령) / 기타(헌장) | 내규관리규정 제2조 (취업규칙은 규정, 행동강령·윤리강령은 지침) | 파일명 그대로 |
| 의존성은 uv 프로젝트(olefile, pypdf, pytest) | 기존 PC에 uv 설치됨 | pip |

## 전처리 (같은 날 추가)
원칙: 원문 `text`는 근거 표시·신·구조문대비표용으로 그대로 두고, 비교·검색·LLM 입력용 `norm`을 따로 만든다.

| 처리 | 대상 (90건 기준) | 위치 |
|---|---|---|
| 개정 표시 제거 → 항목별 `amend_marks`로 분리 | 본문 안 약 1,150개 (`<개정 …>`, `[… 개정]`) | `norm`, `amend_marks` |
| 따옴표·가운뎃점·전각 기호 통일 | 곡선 따옴표 약 260, 가운뎃점 변형 약 510 | `norm` (규정명 인용 매칭에 필요: 복지·후생 vs 복지ㆍ후생) |
| 연속 공백 정리, 띄어쓴 제목 비교(`compact`) | 「퇴 직 금 지 급 규 정」 등 | `norm`, 비교 함수 |
| PDF 쪽번호 줄 제거 | 윤리강령 「- 5 -」 등 | 추출 단계 |
| 머리말(내규집 목차 번호 + 문서명) 분리 | 대부분 문서 | `headers`, 본문·연혁에서 제외 |

머리말에 다른 규정명이 들어간 문서 4건은 원문 표기 오류 후보로 `header_mismatch`에 남긴다: 직제규정·직제지침(「이사회규정」), 홍보업무지침(「사옥관리지침」), 퇴직금지급규정(「퇴직급지급규정」 오타).
남겨 두는 것: 「주)」 각주(규범 내용), 조문 안의 표 조각(8곳, 수치 점검에 필요할 수 있음).
