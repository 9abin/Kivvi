## 요약
담당자가 기준선 이슈와 개정안(대비표 행·영향 항목)을 하나씩 열어 보고 결정을 남기는 화면. 결정은 `eval/review_log.jsonl`에 덧붙이기만 한다.
화면 3개: 기준선 이슈(목록·상세·원문 조문·관련 조항·결정) / 개정안 검토(새 개정문 입력 → 적용·점검, 대비표 행 수락·거절, 영향 항목 판단) / 검토 현황(범위별 상태, 최근 결정, 원장 후보 CSV).
실행: `uv run streamlit run app/review_app.py`

| 결정은 결과 ID가 아니라 고정 열쇠(위치·문구·종류 해시)로 연결 | F00012 같은 ID는 점검을 다시 돌리면 바뀜 | 결과 ID |
