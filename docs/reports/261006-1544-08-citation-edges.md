## 요약
조문 `norm`에서 인용(조·항·호·장, 규정명, 법령, 별표·별지)을 뽑아 엣지로 만들고, 대상이 실제로 있는지 확인했다.
담당 21건: 엣지 442개. 1주차 사람 검토 §C 중 인용이 명시된 13건에서 **구조 검사 대상 11건을 모두 탐지**했다. 나머지 3건(C2, C5, C12)은 대상이 존재해 의미 검사가 필요하다.
90건 법령 인용을 정식 이름으로 묶어 130종 목록을 만들었다 (`out/edges/laws_all.tsv`, 한석희 법률 DB 대상 범위용).

## 엣지 상태값
| status | 뜻 | 대응 오류 유형 (02-specs) |

| `name_mismatch` | 규정명이 공개 규정과 다름 (유사도 0.8 이상) | 규정 간 인용 오류 |
| `unknown_regulation` | 공개 90건에 없는 규정명 | 규정 간 인용 오류 후보, 또는 비공개 내규 |

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 판정은 하지 않고 구조적 사실만 status로 기록 | AGENTS §3. 오류 확정은 사람 검토 | 오류/정상 이분 |
| 인용 문서 판정 순서: 「」 → 개정문 안 옛 문구 제외 → 자기 참조(이·본·동 규정) → 동법·같은 법 → 약칭 → 공개 규정명 → 법령명 → 괄호 없는 규정명 → 부칙 개정 대상 | 표기 형태별로 오탐을 하나씩 막으며 정한 순서 | 단일 정규식 |
| 나열 인용(「제4조 제6호, 제12호 및 제13호」, 「제49조 제2항 및 제62조」)은 앞 인용의 문서를 상속 | 두 번째 이후 인용은 문서명이 생략됨 | 매번 판정 |
| 괄호 없는 규정명은 왼쪽으로 단어를 붙이다가 조사로 끝나는 단어·일반어에서 멈춤 | 「고려하여 당사 규정」, 「항의 규정」 같은 문장 조각 오탐 제거 | 고정 길이 |
| 「…강령」은 법령이 아님 ('령'으로 끝나도) | 「임직원행동강령」이 법령으로 분류되던 문제 | — |
| 부칙 「「X」 일부를 다음과 같이 개정한다」 이후 인용은 X 기준, 따옴표 안 옛 문구는 해석 안 함 | 직제규정 부칙의 타 지침 개정문 오탐 | — |
| 인용 제목 대조(`title_mismatch`)를 규칙으로 추가 | Definely "제목 불일치". C3·C11을 의미 검사 없이 잡음 | 의미 검사로 미룸 |
| 약칭 사전은 90건 전체에서 수집, 문서 안 정의가 우선 | 업무지침의 「특정금융정보법」은 업무규정에서 정의 | 문서별만 |
| 정의 없는 약칭은 추정하지 않고 「(약칭 미해석)」 표시 | 추정은 근거 없는 판단. 그 자체가 표기 오류 후보 | 가장 많이 인용한 법으로 추정 |
