# 261102-1730 3차 봉인 평가 사전 등록

- 관련: [76 2차 결과](261102-1700-76-sealed-round2-result.md), [75 2차 계획](261102-1600-75-sealed-round2-plan.md)
- 이유: 2차 문항을 본 뒤 코드를 고쳤다(아래). 2차는 이제 개발용이다. 고친 효과는 **한 번도 보지 않은 문항 12개**에서만 말할 수 있다. 결과를 보기 전에 지표와 목표를 여기에 적어 둔다.

## 2차를 본 뒤 고친 것 (모두 2차 진단에서 원인이 구체적으로 나온 것)

1. 번호 이동: 이동 범위의 조도 후보로 허용(의미 검색 · 문구 경로), 이동하는 조끼리의 내부 인용(`CITES_internal`)을 확정급으로, 신설 조문 본문으로도 의미 검색(`RAG_NEW`).
2. 수정 종류 분류: 정의 항목 아래 열거(호 · 목)를 고치면 정의 변경으로, 「X이/가 정한다」를 위임으로.
3. 법령 개정: 법령 노드가 없어도 개정문의 핵심 말 검색과 의미 검색으로 처리(`analyze_law`).
4. 단계 원칙: 확정급은 번호 · 이름으로 **직접 인용**한 경우만(`CITES_in`, `STALE_CITE`, `CITES_internal`, 규정명+제목어). 용어 사용(`USES_TERM`)은 확인 권장으로 내렸다. 근거: 용어 사용의 정밀도가 같은 규정/다른 규정으로 깔끔히 갈리지 않고(1차 봉인 같은 규정 12/13, 2차 3/19) 의미 판단이 필요하다.
- 고친 뒤 이미 본 문항 수치(독립 평가 아님): 개발 재현율@20 78%, 확정급 26/26, 확정급+권장 101개 읽으면 90%. 2차 재현율@20 82%, 도달 91%.

## 지표와 목표 (3차에서 한 번 잰다. 결과를 보고 지표를 바꾸지 않는다)

| # | 지표 | 목표 | 판정 |
|---|---|---|---|
| 1 | 후보 20개 안 정답, 합침 − RAG만 (문항 단위 bootstrap) | 점추정 +10%p 이상 | 구간 하한이 0 이상이면 「우위」, 아니면 「불확실」이라고 쓴다 |
| 2 | 확정급 + 확인 권장을 읽었을 때 정답 비율 | 60% 이상 | 읽은 후보 수를 함께 쓴다 |
| 3 | 확정급 정밀도 | 70% 이상 | 확정급 후보가 10개 미만이면 「표본 부족」 |
| 4 | 영향 없음 문항의 확정급 오경보 | 0 | |
| 5 | 확정급 카드의 근거 문장 확보율 | 100% | 치환안의 정확성은 사람이 따로 본다 |
| 6 | 도달 재현율 | 80% 이상 | 풀에 든 정답 비율 |

- 목표를 못 넘으면 넘지 못했다고 쓴다. 결과가 좋아도 라벨이 AI 초안이고 문항이 12개라서 「탐색적」이라고 쓴다.
- 보고에 쓰는 수치는 이 표의 지표와 수정 종류별 문항별 결과로 한정한다.
