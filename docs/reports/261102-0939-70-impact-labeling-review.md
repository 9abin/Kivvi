## 요약
개정 24건, 독립 라벨 두 벌, C의 불일치 검토를 완료했다. 최종 초안은 영향 157건·제외 3건·낮은 확신 2건이다.
실제 구성은 영향 있음 13문항·없음 11문항으로, 설계의 20·4를 충족하지 않는다. 사람 검토 전에는 정답 변환·해시 확정·봉인 실행을 하지 않는다.

## 산출물과 수치

키트의 [산출 폴더](../../eval/impact_label_kit/산출/)에 저장했다.

| 산출물·지표 | 결과 |
|---|---|
| `changes.jsonl` | 24줄, 개발 8 / 봉인 16, 종류별 수·규정 제한 충족 |
| `labels_B1.jsonl` / `labels_B2.jsonl` | 각각 24줄, 영향 제안 149 / 142건 |
| 두 라벨러 합집합 / 공통 제안 | 160 / 131건 |
| 불일치 | 후보 29/160 = 18.125%, 문항 11/24 = 45.83% |
| `labels_final.jsonl` | 24줄, 공통 131 + 한쪽 제안 인정 26 = 영향 157건 |
| 제외 / 낮은 확신 | 3 / 2건 |
| 의도한 통제 4문항 | I07·I08·I23·I24 모두 양측 무영향 합의 |
| 계획 외 무영향 | I06·I10·I11·I12·I14·I15·I17 (7건) |
| 분할별 실제 영향 있음 / 없음 | 개발 5 / 3, 봉인 8 / 8 |

건수는 `(문항 id, 규정, 조)` 단위다. 같은 조가 다른 개정에서 영향을 받으면 각각 센다. [사람 검토표](../../eval/impact_label_kit/산출/사람검토.md)에 개정문·제외·낮은 확신·한쪽 제안 인정·무영향 이유·부칙 식별 확인을 모았다. 원문 근거 일치는 의미 판단의 정확성을 보증하지 않는다.

## 주요 결정

| 결정 | 이유 | 택하지 않은 대안 |
|---|---|---|
| A → B1/B2 → C를 대화 이력이 없는 별도 에이전트로 실행 | 작성자·라벨러·결정자 역할을 분리하고 B1/B2 결과를 상호 비공개로 유지 | 같은 대화에서 역할 전환 |
| 난수 추출 순서·탈락 이유를 보관 | 인용 수를 보고 조를 선택하지 않은 과정을 추적 | 영향 라벨을 보고 개정을 교체 |
| 원본 `validate.py` 보존, 보완 검사 별도 추가 | 실제 원문의 `제12-1조`를 원본 검사기가 인식하지 못함 | 실제 영향 조 삭제·조 번호 변조 |
| 13·11 구성과 계획의 차이를 공개 | A의 무작위 선택은 영향 있음 20건을 보장하지 않음 | 목표 수를 맞추려고 라벨을 만들거나 이번 결과를 보고 조를 재선정 |
| 사람 검토 전 정답 확정 보류 | 보고서 69 실행 순서 4→5: 사람이 제외·낮은 확신을 본 뒤 정답 확정 | `labels_final`이라는 이름만으로 확정 취급 |

## 검증

실행기는 `.venv/Scripts/python.exe`다. 기본 `python`은 이 환경에서 Windows 실행 별칭으로 연결되어 동작하지 않았다. 작업 디렉터리는 `eval/impact_label_kit`이다.

```powershell
& ../../.venv/Scripts/python.exe validate.py changes 산출/changes.jsonl
& ../../.venv/Scripts/python.exe validate.py labels 산출/labels_B2.jsonl 산출/changes.jsonl
& ../../.venv/Scripts/python.exe 산출/validate_extended.py labels 산출/labels_B1.jsonl 산출/changes.jsonl
& ../../.venv/Scripts/python.exe 산출/validate_extended.py labels 산출/labels_B2.jsonl 산출/changes.jsonl
& ../../.venv/Scripts/python.exe 산출/validate_extended.py labels 산출/labels_final.jsonl 산출/changes.jsonl
& ../../.venv/Scripts/python.exe 산출/audit_outputs.py
```

- 위 검사 모두 통과. 원본 검사기로 B1·final을 검사하면 I18의 `전산업무지침 제12-1조` 1건만 실패한다. 실제 원문에 있는 번호이며 보완 검사는 그 표기를 추가 인식한다. 상세는 `B1_validation_notes.txt`, `C_validation_notes.txt`.
- `audit_outputs.py`: 24개 고유 ID, 분할·종류·규정 제한, 영향 중복, 공통 제안 보존, 불일치 전건의 인정·제외 및 라벨러 출처를 교차 확인했다. 구조 오류 0, 해당 조·서식 구간의 근거문장 불일치 0.
- 규정 90개·지시서·규정목록·원본 검사기·개정문 총 94개 파일이 라벨링 시작 시 기록한 `source_manifest.json`의 해시와 일치한다.
- `audit_summary.json`에 상세 수치와 **초안** 해시를 보관했다. 이 해시는 실행용 봉인 해시가 아니다. 원본 규정·산출물을 커밋하거나 외부 게시하지 않았다.

## 한계와 사람 확인 사항

1. 별도 대화 이력으로 분리했지만 같은 모델 설정을 사용했다. 사람 둘·다른 모델의 독립 판단이나 전문가 검수가 아니다. 폴더 밖 자료 금지는 역할 지시로 적용했고 별도 파일시스템 격리는 하지 않았다.
2. 계획 외 무영향 7건의 누락 여부와, 영향 있음 13·없음 11 구성을 그대로 탐색용으로 쓸지 새 독립 작성 배치를 만들지 결정해야 한다. 이번 결과를 보고 조를 고르는 보충은 선택 편향을 남긴다.
3. I02의 `인사규정 제2조`는 부칙 적용례를 근거로 삼았다. 현재 `(규정, 조)` 키는 본문과 부칙의 같은 번호를 구별하지 못하므로 정답 변환 전에 식별 기준을 확인해야 한다.
4. 최종 초안에서 I03·I04·I20·I22의 영향 수는 각각 22·24·29·31건이다. 권장 후보 상한 20에서는 전부 찾을 수 없다는 점을 이후 평가 계획에 기록해야 한다. 이번에 상한을 바꾸거나 시스템을 실행하지 않았다.
