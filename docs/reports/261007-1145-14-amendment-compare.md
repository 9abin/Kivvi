## 요약
개정문(「제30조제2항 중 "A"를 "B"로 한다.」)을 해석해 규정 **사본**에 적용하고, 현행·개정안을 나란히 놓고 바뀐 부분에 밑줄을 친 대비표를 만든다.
시나리오 S01(값 변경)·S02(조 삭제)·S03(번호 이동 + 신설, 15개 조문)이 적용되고, 결과 페이지 「대비표」 탭에서 본다.
번호 변경·삭제된 조문의 대응표(`label_map`)를 함께 내보내 다음 단계(변경안 점검: 깨지는 인용 찾기)의 입력으로 쓴다.

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 입력은 개정문 문법 (법제처 개정문 형식) | 내규안(제20조) 작성 자료와 같은 형식, 규칙으로 해석 가능해 재현됨. US House Comparative Print도 같은 방식(문법 기반 개정 실행) | 수정된 전문을 받아 diff (무엇을 바꾸려 했는지 의도가 사라짐) |
| 못 읽는 문장·없는 문구·겹치는 번호는 추측하지 않고 이유와 함께 멈춤 | 잘못 적용된 초안이 근거처럼 보이는 위험이 더 큼 | 가장 비슷한 곳에 적용 |
| 문장은 적힌 순서대로, 각 문장의 번호는 그 시점 번호로 읽음 | 「종전 제7조부터…로 하고, 제7조를 신설한다」 순서가 자연스럽게 맞음 | 모든 번호를 개정 전 기준으로 읽기 |
| 「"A"를 "B"로」는 지정 단위 안의 모든 A를 바꾸고 바꾼 개수를 기록 | 개정문 관례. 개수는 대비표 검토 때 확인 | 첫 번째만 |
| 「제3조제2호」(항 없음)는 항 구분이 없는 조의 호로 읽음 | 실제 표기. 처음엔 조 전체 삭제로 처리하는 버그가 있었고 테스트로 잡음 | — |
| 대비표는 글자 단위 비교로 밑줄, 안 바뀐 항·호는 (생 략)/(현행과 같음), 조 번호가 바뀌면 번호 전체 밑줄, 삭제는 통째로 | 법제처 대비표 관례. 글자 비교만 하면 「제1[0]조」, 「제[2조…]」/「[삭]제」처럼 어색함 | — |
| 현행 문안은 개정 표시(<개정 …>)를 뺀 본문(norm) | 개정 표시는 비교 대상이 아님. 페이지에 명시 | 원문 그대로 |
| 산출물은 `out/changes/{id}/`(changeset.json, compare.html), 원문·규정 DB 불변 | 승인은 개정이 아님 (02-specs) | — |

## 확인한 것
- S01 초안의 개정문은 「분할하는 횟수는 최대」까지 지워 문장이 깨지는 치환이었음 → 대비표로 보고 바로잡음. 문안 실수를 사람이 보기 전에 드러내는 것이 대비표의 쓸모
- 오류 입력 4종(없는 문구, 없는 조, 이미 있는 번호에 신설, 해석 불가 문장)이 모두 이유와 함께 멈춤
- 테스트 32개 통과 (개정 8개 추가)
