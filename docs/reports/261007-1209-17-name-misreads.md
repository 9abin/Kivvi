## 추가 수정 (같은 날)
- 괄호 없는 일반 표현(부칙 「개정 지침에 의한」, 「종전 규정에 의한」)도 인용에서 제외 — 처음엔 괄호 안만 막았음 (241 → 238)
- 검토 화면: 별지·별표·부칙 결과가 앞뒤 60자 문맥 조각만 보여 문장이 잘려 보였음 → 해당 별지·부칙 전체 문안을 인용 위치 표시와 함께 보여 줌. 인용 문구의 「「 」」 이중 괄호 제거

## 잘림 점검 (같은 날, 박형건 지적)
변경안 점검의 「바뀐 조」가 조 전체를 200자로 잘라 현행·개정안이 같아 보였고(바뀐 ②가 잘려 나감), 이유의 「현행 ['2회'] → 개정안 ['4회']」도 조 전체 숫자 집합 차이라 「총 3회」→「최대 3회」처럼 자리만 바뀐 값이 사라져 오해를 불렀다. 저장·표시 데이터를 자르는 곳을 전수 확인했다.

|---|---|---|
| 변경안 점검 「바뀐 조」 | 조 전체 200자 | 바뀐 항만 전체 문안, 화면에서 대비표처럼 밑줄 |
| 변경안 점검 이유 | 조 전체 숫자 집합 차이 | 개정문의 실제 문구 쌍 + 바뀐 항의 값 전체 |
