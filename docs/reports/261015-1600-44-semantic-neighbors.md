## 요약
변경안 점검의 의미 유사(벡터 실시간 검색)는 기본으로 꺼져 있어, 제목이 다른 같은 주제 조문은 인용이나 정의 용어가 없으면 찾지 못했다.
조문 대 조문 유사도를 미리 계산한 「의미 이웃」 표(조 607개, 이웃 쌍 1,003개, 그중 인용으로도 이어진 쌍 52개 = 5%)를 만들고, 바뀐 조의 이웃을 낮은 우선순위 「확인 필요」로 낸다.
변경안 골든셋 183문항에서 기존 결과는 그대로(높은 우선순위 오경보 0, 실제 사례 S01~S03 그대로)이고, 이웃 카드는 62문항에서 합계 110장(문항당 최대 4장) 더해진다. 정밀도는 표본 30쌍 사람 판정 대기.

## 점검에서의 처리
| 항목 | 규칙 |
|---|---|
| 후보 | 바뀐 조(내용 변경·삭제)의 이웃 중 같은 규정이 아니고 이미 같은 제목 후보가 아닌 것 |
| 분류 | 확인 필요(review), 우선순위 낮음. 새 충돌로 판정하지 않음 |
| 이유 문구 | 「같은 주제로 보이는 다른 규정 조문 (조문끼리의 의미 유사도로 찾음) — 바뀐 내용과 맞는지 확인」. 상대 조문에 현행 값(숫자·단위)이 그대로 있으면 「개정안 값과 맞춰야 하는지 확인」을 덧붙임 |
| 켜는 곳 | 화면의 개정안 작성(`web_agent.draft`), 골든셋 `--neighbors`. 표 파일이 없으면 자동으로 꺼짐 |
| 확인한 범위 | 의미 이웃이 켜지면 「의미 유사」 경로를 켜진 것으로 표시 |

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 미리 계산한 표 (조문 대 조문) | 화면 서버가 개정안마다 임베딩 모델을 올리지 않아도 됨. 질문 대 조문보다 어휘가 비슷해 검색이 쉬움 | 기존 실시간 벡터 검색 (모델 적재, 제목+첫 문장 질의) |
| 흔한 제목(목적·정의·시행일 등)은 양쪽 다 제외 | 모든 규정의 「목적」 조가 서로 비슷해 보임 | 포함 |
| 낮은 우선순위의 확인 필요로만 | 같은 주제여도 영향이 없을 수 있음. 오경보가 높은 우선순위로 올라가면 신뢰를 잃음 | 값이 다르면 새 충돌 후보 |
| 정의 조는 의미 이웃에서 빠짐 | 「정의」가 흔한 제목. 정의 조의 영향은 정의 용어 경로(리포트 43)가 맡음 | 포함 |
