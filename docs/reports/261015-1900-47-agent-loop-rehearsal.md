## 요약
「모니터링(찾기)에서 끝나지 않고 고칠 초안까지 가져오는」 연결을 넣었다. ① 변경 감시의 새 결과마다 「초안 가능 / 현업 판단 필요」를 붙이고, 초안 가능한 법령명 변경은 일괄 정비로 바로 이어진다. ② 개정안을 공포하면 수락한 함께 개정안이 다른 내규의 초안으로 자동 생성된다(공포된 개정이 반영된 본문 기준으로 다시 점검). ③ 규정·조를 모르는 요청도 고칠 후보 조문 3개를 찾아 사람이 고르게 했다.
시연 흐름을 API로 끝까지 돌렸다: 개정안 작성(11초) → 카드 수락 → 제출 → 기안자 본인 승인 거부 → 승인 → 공포 → 함께 개정 초안(징계지침 제18조 「제15조」 → 「제16조」) 자동 생성. 리허설에서 버그 2건·한계 3건을 찾았다.

## 1. 감시 → 초안 (내규 공포 → 따라 고칠 곳 포함)

| 내규 개정 공포 | 수락한 「인용받음」 고침으로 다른 내규별 개정문 → 초안(`F…`, kind=companion, origin=원 개정안). 같은 원 개정안의 초안이 이미 있으면 건너뜀 | 승진지침 신설·번호 밀기 공포 → 징계지침 초안 1건, 공포된 본문 기준이라 영향 카드 0 |
- 공포 자체는 함께 개정 초안 생성이 실패해도 끝난다 (실패는 알림으로만).

## 2. 개정 위치 찾기 (`regcheck.target`, 화면: 조문 열기 검색창)
규정명·조 번호가 없으면 요청으로 고칠 후보 조문 3개를 찾는다. 요청에 규정 이름이 있으면 그 규정 안에서, 없으면 전체 벡터 검색 25개 + reranker. 1위 점수가 0.3 아래면 로컬 LLM이 규정 용어로 바꿔 쓰고 원래 요청과 합쳐 다시 찾는다. 그래도 낮으면 「확실하지 않음, 규정 이름을 적어 달라」.
| 요청 (규정 이름 없음) | 결과 |
|---|---|
| 승진 심사 결과를 공개하도록 하고 싶다 | 1위 승진지침 제11조(승진심사 결과의 공개) 0.81 |
| 육아휴직을 더 여러 번 나눠 쓰고 싶다 | 1위 취업규칙 제43조, 2위 인사규정 제30조 (둘 다 고칠 곳) |
| 법인카드를 주말에도 쓸 수 있게 | 1위 법인카드 사용지침 제8조(사용기준) |
| 반반차를 없애고 싶다 | 확실하지 않음 (2위 유연근무제 운영지침 제23조) |
| 출장 숙박비 기준을 올리고 싶다 | 확실하지 않음, 여비규정 제14조(체재비)를 못 찾음 — 숙박비 ↔ 체재비 어휘 차이 |
- 바꿔 쓴 검색어만 쓰면 원래 낱말을 잃었다(「출장 숙박비」 → 「출장비 기준 조정」) → 원래 요청과 합쳐 찾게 고침.
- 응답: 처음 22~64초 → 0.4~7초. 채팅이 올린 같은 임베딩·reranker 모델을 재사용하고 후보 40 → 25개, 조문 700 → 400자. GPU 8GB 중 7.8GB 사용(채팅 모델 + Ollama)이 느린 원인.
- 평가는 5개 요청뿐이다. 팀원 개정 요청셋(`eval/agent/nl_request_form.md`)을 받으면 「후보 3개 안 정답」으로 잰다.

## 3. 근거 종류 표시
영향 카드마다 발견 경로로 근거 종류를 붙인다(`change_check.basis_of`): 문서 명시(인용·위임·조 번호·법령 DB) / 낱말 일치(같은 제목·정의 용어) / 모델 추정(의미 유사·의미 이웃·오타, 점선 테두리). 기준선 결과에도 `basis`(리포트 46). 「도메인 판단이 필요한 곳」을 화면에서 구분하기 위함.

## 후속 1 (261015): 신설 조문의 같은 내규 안 중복 확인
- 신설 조문(제목 + 본문 400자)을 임베딩해 같은 내규의 기존 조문과 비교한다 (`change_check`의 4-3 경로, 새 조문끼리는 비교하지 않음). 같은 내규 안 조문(항)의 최고 이웃 점수는 중앙값 0.76·90% 지점 0.84, 관계없는 새 조문은 0.6 안팎, 리허설의 중복은 0.83.
- 기준: 0.82 이상 「중간」, 0.78~0.82 「낮음」(인접 주제가 많음), 조문마다 최대 2개. 화면 개정안 작성에서 켜지고, 「확인한 범위」의 의미 유사가 켜진 것으로 표시됨.
- 리허설 재현: 같은 요청에서 「신설하는 제15조(승진결과 공개)와 같은 내규의 기존 제11조(승진심사 결과의 공개)가 비슷함 (0.83)」 카드가 나옴 (시험 개정안 `W261015-144027`은 반려).
- 과거 신설 88건에 대한 사후 점검: 21건에서 0.78 이상 겹침. 같은 개정에서 함께 신설한 연속 조문(전산업무지침 제12조의1~6)과 인접 주제(문서의 분류 ↔ 보존기간)가 대부분이라, 실제 점검(새 조문끼리 비교 안 함)에서는 이보다 적다. 진짜 중복이었는지는 현업 확인이 필요하다.
