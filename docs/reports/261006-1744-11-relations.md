## 요약
영향 분석의 기반인 **관련 조항 표**를 만들었다. 관계마다 근거 문구, 출처, 신뢰도, 검증 상태, 원문 버전을 붙인다 (90건, 1,848개).
표본 검수로 관계의 정확도를 쟀다. 1차 표본에서 조문 인용 정확도가 **57%**로 낮게 나왔고, 원인 5가지를 고친 뒤 새 표본에서 **80%**였다. 2차에서 나온 오류 3건도 고쳤으며, 고친 뒤의 정확도는 아직 새 표본으로 재지 않았다.
라벨은 Claude가 원문과 대조해 붙였다. 사람 확인이 필요하다.

## 설계 결정 (대화로 확정)
| 결정 | 이유 | 대안 |
|---|---|---|
| 영향 관계는 미리 연결해 표로 저장하고, 수정할 때는 조회만 한다 | 매번 검색·추론하면 비용이 들고 결과가 흔들림 | 수정할 때마다 RAG 검색 |
| "그래프"는 그래프 DB가 아니라 관계 표 하나 + 역방향 조회 | 벡터 검색만으로는 인용받는 조를 상위 10개에서 64%, 30개에서 81%만 찾음. 표 조회는 정의상 전부 찾음. 조→조 인용 458개, 84%의 조는 인용받지 않고, 3단계까지 따라가도 최대 27개 | Neo4j, GraphRAG |
| 영향 관계는 유사도가 아니라 같은 열쇠(조문 번호, 용어, 대상·속성)로 연결 | 유사도는 "비슷한 말", 영향도는 "의존". 예: 징계 '면직' 변경 → 퇴직금지급규정 제7조 「징계 해직」은 문장이 비슷하지 않음 | 임베딩 유사도로 연결 |
| 임베딩은 관계를 만드는 과정의 보조 (표현이 다른 같은 개념 찾기) | 키워드 대비 '당연해직 → 당연면직' 34위 vs 1위. 같은 단어 쓰는 J3·J4는 키워드도 1위 | 임베딩 중심 |
| 관계마다 근거 문구·출처·신뢰도·검증 상태·원문 버전 | 잘못된 관계를 나중에 거르기 위함. 사람 결정은 다시 만들어도 유지 | 관계만 저장 |
| 부칙에서 나온 관계는 '후보'(필수 점검에 안 씀) | 부칙은 옛 번호·옛 문구가 많음 | 동일 취급 |

## 관련 조항 표 (`out/relations/relations.jsonl`)
| 컬럼 | 뜻 |
|---|---|
| src / src_article / src_kind | 출발 단위(항·호), 출발 조, 본문·부칙·별표·별지 |
| target / target_type / kind | 대상, 유형, 관계 종류(인용, 문서 인용·위임, 법령 인용, 별표·별지 인용) |
| evidence / context | 원문 표현과 문맥 (근거 없는 관계는 만들지 않음) |
| source | rule / embedding / llm / human |
| confidence | 확실(필수 점검) / 후보(참고) |
| verification | 자동 / 의심(구조 검사에서 걸림) / 확인됨 / 기각 |
| check_status, note | 구조 검사 결과와 설명 |
| src_version / target_version | 출발·대상 규정 개정일 |
사람 결정은 `eval/relation_decisions.json`(키: 출발 단위|근거 표현)에 두면 표를 다시 만들어도 반영된다. 조회는 `Related.lookup(조 ID)` (인용함 / 인용받음 / 규정 단위로 인용받음).
예외·정의-사용·같은 기준(값) 관계는 다음 단계에서 같은 표에 추가한다.

## 정확도 측정
판정 기준: "원문에 적힌 대로 대상을 해석했는가". 원문 자체가 틀린 인용(C2 등)은 여기서 보지 않는다 (그건 점검 대상).

### 1차 표본 (51개, 종류별 층화, 수정 전)
| 종류 | 표본 | 정확 | 애매 | 오류 | 정확도 |
|---|---|---|---|---|---|
| 조문 인용 | 28 | 16 | 2 | 10 | **57%** |
| 문서 인용·위임 | 8 | 7 | 1 | 0 | 88% |
| 법령 인용 | 10 | 9 | 1 | 0 | 90% |
| 별표·별지 인용 | 5 | 5 | 0 | 0 | 100% |
오류 원인: 개정 이력 표기 「[제11조에서 이동, 종전 …]」를 인용으로 해석(6), 법령 「규칙 제N조」 약칭을 자기 규정으로(3), 준용 법률 조문 목록(1, 의심 표시는 됨).
애매: 외부 규정·고시를 '공개 90건에 없는 규정'으로 분류(3), 「同시행규칙」 이름 불완전(1).

### 수정 1 → 2차 표본 (조문 인용 25개, 1차와 겹치지 않게)
정확 20, 애매 2, 오류 3 → **80%** (애매 제외 87%).
오류 원인: 「제9조2(…)」 가지번호 조문 미인식, 별표 뒤 부칙을 별표로 읽음, 약칭 정의 「지침은 감사규정」 잡음.

### 수정 2
위 3건 수정 후 해당 항목이 모두 정상 해석됨을 확인. 1주차 정답 대조 11/11 유지. 본문 조 2,042 → 2,043.
**수정 2 이후의 정확도는 새 표본으로 아직 재지 않았다** (같은 표본으로 다시 재면 부풀려짐).
