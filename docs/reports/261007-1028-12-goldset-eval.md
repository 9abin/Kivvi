| 결정 | 이유 | 대안 |
|---|---|---|
| 정답 = 사람이 찾아 고친 오류(가빈 corrections + 1주차), 에이전트는 원문만 읽고 탐지 | 실제 오류이고 시스템과 독립적으로 만들어짐 | 시스템 후보를 사람이 확인한 것만 정답 |

| 종류별 채점, 오탈자는 범위 밖으로 따로 | 섞으면 수치 왜곡. 맞춤법 검사 포함 여부는 미결 | 한 숫자 |

| 의미 후보를 우선순위로 나눔: 높음(설명구) / 낮음(벡터 1단계만) | 낮음을 빼면 21건 밖 실제 오류를 놓침 | 높음만 결과로 |
