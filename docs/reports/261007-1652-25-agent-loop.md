- S03(직제규정 제7조 신설·번호 이동): **같은 규정 깨짐 10 → 0** (1회차, 개정문 6문장 추가), 함께 개정안 7개 규정(직무전결규정 별표 1곳은 수작업), 부칙 초안
- S02(제37조 삭제): 기계적으로 고칠 수 없음 → 질의서 3건 (근거 소멸 2, 삭제 사유)
- S01(값 변경): 깨짐 없음, 법령 대조 1 (남녀고용평등법 제19조)
- LLM 없음. 출력: `out/changes/{id}/package.json`, `package.html`

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 연쇄 수정은 개정문 문장으로 추가 (사본에 직접 고치지 않음) | 결과가 그대로 내규안이 되고, 같은 적용기·대비표로 검증 | 텍스트 직접 수정 (검증 불가) |
| 고칠 문장의 조 번호는 번호 이동 **후** 번호 | 문장은 차례로 적용되므로 옮겨진 조(옛 제8조 → 제9조)는 새 번호로 가리켜야 함 | 옛 번호 (적용 실패) |
| 여러 쌍 치환은 **동시에**, 인용 문구는 경계 검사 | 「"제7조"→"제8조", "제8조"→"제9조"」가 연달아 적용되면 새 제8조가 다시 바뀜. 「제7조」가 「제7조의2」에 맞으면 안 됨 | 차례 치환 (버그) |
| 고친 인용은 루프가 기록해 점검에 넘김 | 관련 조항 표는 원문 기준이라 고쳐도 계속 깨짐으로 보임. 문구 비교만으로는 「제7조와 제8조」에서 헷갈림 | 문구 비교만 |
| 다른 규정은 고르게 함 (부칙 관계 조항 vs 함께 개정) | 내규 관행상 둘 다 쓰임. 어느 쪽이 맞는지는 회사 결정 | 하나로 정함 |
| 인용 번호만 고친 조는 같은 주제·법령 대조 제외 | 연쇄 수정 때문에 「대표이사」 조가 바뀐 것으로 보여 상법 제389조 대조가 뜨는 잡음 | — |
| 별표·별지·부칙 안 인용은 수작업 목록 | 개정문 적용기가 그 단위를 다루지 않음 | 억지 문장 (적용 실패) |
