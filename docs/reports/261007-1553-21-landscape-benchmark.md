## 요약
- 공공기관은 기관당 내부규정 약 100개를 HWP로 관리하며 알리오에 공시한다. 규정은 서로 엮여 있고(KVIC: 90개 중 64개가 다른 규정을 인용) 자주 바뀐다(KVIC 연 49건).
- 영향 분석 기능 자체는 이미 시장에 있다(법령↔조례, 외부 규제↔사내 정책). 사내 시스템이므로 **검증된 기능은 벤치마킹해 가져오고**, 공개 사례에서 찾지 못한 **내규 간 조문 단위 연쇄 영향 + 검증 + 개정 이력**에 집중한다.

## 2. KVIC 실측 (공개 규정 90건, `out/` 기준)
| 항목 | 값 |
|---|---|
| 규정 수 (위계) | 90 (지침 64, 규정 24, 정관 1, 기타 1) |
| 파일 형식 | HWP 84, HWPX 3, PDF 3 |
| 본문 조 | 2,049 (규정당 평균 22.8, 최대 회계규정 77) |
| 별표·별지 | 별표 105, 별지 316 |
| 인용 관계 | 1,848 (같은 규정 안 847, **다른 규정 361**, 법령 622) |
| 엮임 정도 | **90개 중 64개가 다른 규정을 인용**, 72개가 다른 규정에서 인용받음, 50개가 법령 인용 (법령 132종) |
| 많이 인용받는 규정 | 인사규정 54, 직제규정 36, 정관 23, 직제지침 20, 징계지침 16, 정보보안관리지침 13 |
| 개정 빈도 | 연평균 49건(2021~2025), 하루 15개 규정 동시 개정(2026.8.28, 직책·조직 명칭 변경) |
| 최종 개정 연도 | 2025~2026년 51개, 2020~2024년 36개, 그 이전 3개 |
| 점검 후보 | 238건(63개 규정): 대상 불일치 125, 대상 없음 73, 규정명 27, 제목 불일치 10, 번호 이상 3 |
| 확인된 오류 원인 | 인용 오류 17건 중 15건이 **상대 규정 개정 뒤 미반영** (예: 성과급지급지침 제1조, 감사지침 4곳) |
| 독립 평가 | 가빈 corrections 범위 23행 중 17 탐지, 사람이 「맞음」 확인한 10곳 오탐 0 |

해석: 허브 규정(인사·직제·정관)이 바뀌면 영향이 수십 곳으로 퍼진다. 허브는 자주 바뀌고(직제 개편), 인용하는 쪽은 소관 부서가 달라 따라가지 못한다.

**우리 것** (공개 자료 범위에서 찾지 못함)
1. 내규 간 조문 단위 인용을 원문에서 자동 추출해 미리 연결 (사람이 매핑하지 않음)
2. 개정안 하나 → 깨짐·해소·확인 필요 → 연쇄 수정안 → 다시 점검 (에이전트 루프)
3. 규칙 기반 적용·검증: 틀린 개정문은 멈춤, 결과 재현·역추적 (생성형 적용 연구 성공률 63%와 대비)
4. 개정 이력으로 "상대가 바뀐 뒤 따라가지 않은 곳" 탐지
5. 폐쇄망·로컬 모델

## 6. 발표 흐름 (제안)
1. 현황: 공공기관 규정 기관당 약 100개, HWP, 수시 공시 / 정비 수요(법제처 9,117, 권익위 4,722)
2. KVIC 실측: 90개 중 64개가 서로 인용, 연 49건 개정, 하루 15건 / 인용 오류 17건 중 15건이 미반영
3. 사례: 2025.3 급여규정 → 성과급지급지침 1년 6개월 / 감사규정 전부개정 → 감사지침 4곳
4. 기존 도구: 검색·대비표·외부 규제 매핑은 있음 (벤치마킹 표)
5. 우리: 내규 간 연쇄 영향 + 수정안 + 검증 (시연: 과거 재현, 직제 개편)
6. 평가: 독립 23행 중 17, 정상 10곳 오탐 0 / 한계와 다음 단계
