# 261102-1930 4차 봉인 평가 사전 등록

- 관련: [78 3차 결과](261102-1830-78-sealed-round3-result.md), [77 3차 사전 등록](261102-1730-77-round3-prereg.md)
- 이유: 3차 결과(목표 대부분 미달)를 본 뒤 원인이 구체적으로 나온 개선 3건을 넣었다. 3차는 이제 개발용이다. 개선 효과는 **한 번도 보지 않은 문항 12개**에서만 말할 수 있다. 결과를 보기 전에 지표와 목표를 여기에 적는다.

## 3차를 본 뒤 고친 것

1. `amend.py`: 「제2조제3호」처럼 항 없이 호만 쓴 개정문을 번호 목록이 항 자리로 읽힌 조에서도 읽는다(기존 해석이 실패할 때만) → 3차 I44 분석 실패 해소.
2. `evidence.py`: 함께 이동하는 다른 조를 번호로 인용하는 후보(`CITES_internal`)에 근거 문장과 치환안.
3. `collect.py`: 삭제 시 지운 조 본문의 희귀 낱말(나오는 조 12개 이하)로 문구 검색(`DELETED_TERM`) → 3차 I39 정답 1/5가 5/5로.
- 이미 본 3차 문항 기준 수치(독립 아님): 합침 @20 77% → 91%, 기본 화면 재현율 82% → 97%, 분석 실패 0. **이 숫자는 개선 효과의 상한이며 4차에서 재현되는지가 질문이다.**
- 3차에서 평가 도구 결함(번호 없는 별지 서식 정답을 못 푼 것) 1건을 정정했다(78의 「정정」). 4차 평가 스크립트 `scripts/eval_round4.py`는 이 정정이 들어간 `impact_eval.py`를 쓴다.

## 지표와 목표 (4차에서 한 번 잰다. 결과를 보고 지표를 바꾸지 않는다)

| # | 지표 | 목표 | 판정 |
|---|---|---|---|
| 1 | 후보 20개 안 정답, 합침 − RAG만 (문항 단위 bootstrap) | 점추정 +10%p 이상 | 구간 하한이 0 이상이면 「우위」, 아니면 「불확실」 |
| 2 | 확정급+권장을 읽었을 때 정답 비율 | 60% 이상 | 읽은 후보 수를 함께 쓴다 |
| 3 | 확정급 정밀도 | 70% 이상 | 확정급 후보가 10개 미만이면 「표본 부족」 |
| 4 | 영향 없음 문항의 확정급 오경보 | 0 | |
| 5 | 확정급 카드의 근거 문장 확보율 | 100% | 치환안 정확성은 사람이 따로 본다 |
| 6 | 도달 재현율 | 80% 이상 | |
| 7 | 기본 화면(RAG 30 + 쓸모 있는 경로의 그래프 20) 재현율 / 문항당 후보 | 재현율 85% 이상, 후보 평균 50개 이하 | 영향 없음 문항의 기본 화면 후보 수도 쓴다 |
| 8 | 분석 실패 문항 / 수정 종류 자동 분류 일치 | 분석 실패 0건 / 일치 보고만 | |

- 목표를 못 넘으면 넘지 못했다고 쓴다. 결과가 좋아도 라벨이 AI 초안이고 문항이 12개라서 「탐색적」이라고 쓴다.
- 4번의 독립 평가(1~4차)를 모두 나란히 보고한다. 하나만 골라 쓰지 않는다.

## 구성과 절차

- 새 가상 개정 12건(I49~I60): 값 변경 2, 삭제 2, 번호 이동 2, 정의 변경 2, 위임 · 법령 변경 2(법령 개정 1), 표현 수정 1, 고립 수정 1. 1~3차 수정 규정은 제외, 법령 개정은 앞의 법령들(특정 금융거래정보 보고 및 이용 등에 관한 법률, 근로기준법, 공공기관의 정보공개에 관한 법률)을 피한다.
- 키트 `eval/impact_label_kit_r4/`(규정 원문 포함, 저장소에 올리지 않는다), 라벨러 A · B1 · B2 · C(Claude 서브에이전트, 폴더 분리). 라벨은 AI 초안.
- 동결: `out/freeze/freeze_r4_20261102.json`(코드 · 프롬프트 P3 · 그래프 해시)을 라벨 작성 전에 기록. 이후 코드 · 규칙 · 프롬프트를 고치지 않는다. 평가 직전에 해시를 다시 확인한다.
- 실행: `scripts/eval_round4.py --yes-open-sealed --kit eval/impact_label_kit_r4/산출`을 한 번, 이어서 LLM 판단 P3(`scripts/run_infer_round4.py`)를 한 번.
