## 원인 진단 (코드는 고치지 않음)

1. **I50(값 변경, 정답 3건 전부 놓침)**: 「연 1회 이상」→「반기 1회 이상」을 자동 분류가 **표현 수정**으로 읽었고(새 실질 낱말 없음), 표현 수정은 후보를 내지 않는다. 기간 단어(연 · 반기 · 분기 · 월)가 바뀌는 값 변경을 값으로 못 읽은 분류 오류. **분류가 틀리면 후보가 0개가 되는 설계 자체가 위험하다**(표현 수정이어도 RAG 후보는 주고 「표현 수정으로 분류됨」이라고 표시하는 것이 안전).
2. I52(삭제): 정답 2건이 RAG 후보에 있었으나 합침 순서에서 20위 밖(24위 · 36위). 기본 화면(RAG 30)에는 1건만 든다.
3. I55(정의 변경): 용어 사용 경로로 5건 중 4건. I60(고립 수정)은 같은 규정의 이웃 조(제7조)를 RAG도 못 찾았다.

- 시스템을 고칠 때마다 직전 평가의 문항에서는 좋아졌지만(3차를 보고 고친 뒤 91%), **새 문항에서는 그만큼 오르지 않았다**(4차 74%). 직전 문항에 맞춘 개선은 새 문항으로 일반화되지 않는다는 뜻이다.
- 네 번 모두 합침이 RAG보다 낮은 적은 없고 차이는 0~22%p였다. 그러나 일관되게 크다고 말할 수 없다. **재현율로 RAG를 이긴다는 주장은 하지 않는다.**
- 달성한 지표는 오경보 0 · 근거 문장 확보 · 분석 실패 0 · 후보 수 같은 **설명 가능성과 절제** 쪽이고, 미달은 모두 **RAG를 이기는 재현율** 쪽이다.

## 결론 (말할 수 있는 것 / 없는 것)

- 말할 수 있다: 규정 수정 영향 후보를 근거 문장과 단계(직접 인용 / 확인 권장 / 참고)로 구분해 보여 준다. 직접 인용 · 이동 구조에서 정확하고(확정급 정밀도는 3~4차에서 100%이나 후보 수가 적다), 영향 없음 문항에서 확정급 오경보는 4번의 평가 중 3~4차에서 0이었다. 재현율은 RAG와 비슷하거나 약간 높다(+0~22%p, 일관되지 않음).
- 말할 수 없다: RAG보다 크게 낫다, 누락 없이, 충돌 판정, 일반화된 우위, 그래프가 모든 관계를 담았다(규칙으로 추출한 텍스트 기반 관계만 있고 법령은 조 단위가 아님).
- 라벨이 AI 초안이고 문항이 적어(독립 평가마다 8~11문항) 모든 수치는 탐색적이다. 정답 사람 확인이 필요하다.

## 다음 과제 (고치면 4차도 개발용이 된다)

1. 표현 수정이어도 RAG 후보는 항상 준다(분류 오류의 비용을 줄이기). 기간 단어 변경을 값 변경으로.
2. 합침 순서 대신 기본 화면(RAG 30 + 그래프 20)을 기본으로(이미 구현).
3. 법령 조 단위 노드(법률 DB 협의), 정답 사람 확인.
4. 더 이상의 평가 반복은 한계 이득이 작다. 남은 시간은 정리 · 사람 확인 · 발표에 쓰는 것을 권한다.
