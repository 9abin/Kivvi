# 261014-1830 합성 질문 생성 파일럿 (GPT-5.4 mini, 프롬프트 v1·v2)

- 관련 문서: [09-embedding-data-guideline](../09-embedding-data-guideline.md), [40 단계 0](261014-1700-40-embed-stage0.md)
- 변경 범위: `scripts/gen_questions.py`(신규), `data/embedding/pilot_*`(git 제외)

## 요약
평가셋과 같은 100개 조(규정마다 한 조씩 + 무작위)로 합성 질문을 만들어 비용·품질·난이도를 쟀다. 입력은 공개된 규정 조문뿐이고 평가 질문은 넣지 않았다.
- **비용은 예상대로다.** v1 348원, v2 448원(100개 조). 전체 2,029조로 환산하면 v1 약 7,400원, v2 약 9,400원(표준), **배치 API면 절반**.
- **자동 검사 통과율은 높다**(v1 95%, v2 96%). 평가 질문과 코사인 0.88 이상은 0개(최대 0.843).
- **질문이 쉽다.** 기본 BGE-m3로 정답 조가 1~3위에 드는 질문이 v1 82%, v2 81%. 학습 신호가 큰 4~100위는 v1 15%, v2 17%.
- **v2에서 효과가 있었던 것은 「간접」뿐이다.** 「혼동」은 효과가 없었다.

## 결과
| 형태 | 질문 수 | 정답 조 1~3위 (쉬움) | 4~100위 (학습 신호) | 낱말 겹침 |
|---|---|---|---|---|
| v1 구어 | 235 | 79% | 19% | 0.54 |
| v1 상황 | 231 | 79% | 17% | 0.31 |
| v1 검색어 | 223 | 90% | 9% | 0.93 |
| v2 구어 | 224 | 80% | 17% | 0.60 |
| **v2 간접** | 220 | **67%** | **29%** | **0.25** |
| v2 혼동 | 220 | 85% | 13% | 0.57 |
| v2 검색어 | 216 | 91% | 8% | 0.91 |
- 간접(조문 낱말을 쓰지 않고 적용 사례로 묻기)이 가장 어렵고 신호가 크다. 4~100위 29%는 상황형(17%)의 1.7배.
- **혼동형은 실패.** 비슷한 조 5개를 보여 줬는데도 모델이 조문을 그대로 되풀이한 질문을 만든다(예: 「일상감사 전에도 필요한 관계 자료를 요구할 수 있나요?」). 쉬운 비율이 구어와 같다. 이 아이디어는 접는다.
- 비슷한 조 5개를 프롬프트에 넣어 입력 토큰이 약 63% 늘었다 (조당 1,276 대 797 토큰). 효과 없이 비용만 늘린 셈.
- 「대상 청크 없음」 110건(v1)은 표기 문제(「(1항)」, 조 전체 청크에 「1항」)였고 검사 쪽에서 맞췄다. v3 프롬프트는 대상 값을 목록에서 고르게 한다.

## 의미
- 질문 하나하나를 어렵게 만드는 데는 한계가 있다. GPT는 조문을 보고 그 조를 겨냥해 쓰므로, 실제 질문처럼 「여러 조 중 비약된 하나」가 되지 않는다. 학습 신호는 **어려운 오답(기본 모델 상위 4~50위의 다른 조)** 을 붙여서 만든다. 쉬운 질문도 오답과 구별하는 학습이 된다.
- v3 제안: 혼동형을 빼고 **간접 2개(서로 다른 사례) + 구어 + 검색어**, 대상 값을 enum으로 고정. 비용은 v1 수준.

## 사람 확인 (진행 중)
- `data/embedding/pilot_review.csv`(v1, 상황 25·구어 13·검색어 12), `pilot_review_v2.csv`(v2, 간접 20·혼동 15·구어 8·검색어 7). 판정 칸: 맞음 / 아님 / 모호. 아님+모호가 10%를 넘으면 프롬프트를 고친다.

## 본 생성 1단계 (프롬프트 v3, 배치 API, 조 1,000개)
- 간접 2개 + 구어 1개 + 검색어 1개, 혼동형 제거, 대상 값은 목록에서만 고르게(strict enum) → 대상 값 오류 0.
- **비용 2,273원** (입력 899,922·출력 571,637 토큰, 배치 절반 단가). 시험 배치(5개 조)는 13원·약 3분, 1,000개 조는 한 시간 안에 완료. 전체 2,026개 조로 환산하면 약 4,600원.
- 질문 5,810개(구어 1,519 · **간접 2,805** · 검색어 1,486), 형식 통과 5,750, **최종 통과 5,316(91%)**. 거른 것: 길이 38, 규정명 22, 평가 질문과 코사인 0.88 이상 2(최대 0.934: 「퇴직금은 언제 나와요?」), 왕복 100위 밖 약 400, 같은 청크 중복 1.

| 형태 | 질문 | 1~3위 (쉬움) | 4~100위 (학습 신호) | 100위 밖 | 낱말 겹침 |
|---|---|---|---|---|---|
| 구어 | 1,519 | 63% | 32% | 6% | 0.38 |
| **간접** | 2,805 | **48%** | **40%** | 12% | **0.18** |
| 검색어 | 1,427 | 94% | 5% | 0% | 0.91 |
| 전체 | 5,750 | 63% | 29% | 7% | |
- v2의 간접(쉬움 67%)보다 v3 간접(쉬움 48%)이 어렵다: 같은 간접 형태인데 청크당 2개를 요구하자 두 번째 사례가 더 멀리 간다. 학습 신호 구간이 40%.
- **위험:** 간접의 12%가 100위 밖이다. 질문이 그 조문과 연결되지 않는 엉뚱한 질문일 가능성이 있어 자동으로 제외했다. 사람 확인(`pilot_review_v3.csv`, 간접 30·구어 10·검색어 10)에서 이 구간의 판정이 중요하다.
- 사람 확인이 끝나면 아님+모호가 10% 이하여야 한다(가이드라인 §7).
