## 발견 경로와 분류 규칙
| 경로 | 찾는 것 | 분류 |
|---|---|---|
| 인용받음 (관련 조항 표 역방향) | 바뀐 조를 번호로 인용하는 곳 | 삭제된 조 → 깨짐(판단 불가). 번호 이동 + 같은 규정 → 깨짐(고칠 수 있음, 새 번호 제안). 다른 규정 → 확인 필요(부칙 「다른 내규와의 관계」 여부에 달림). 내용 변경 → 확인 필요. 부칙에서의 인용 → 참고(오류 제외 원칙) |
| 문서 인용 | 규정 전체를 인용하는 문맥에 바뀐 조의 제목어가 있는 곳 | 확인 필요 |
| 같은 제목 (메타데이터) | 다른 규정의 같은 제목 조 | 값 변경이면 숫자+단위 비교: 개정 후 더 같아지면 해소 후보, 같던 값이 달라지면 새 충돌 후보. 아니면 확인 필요 |
| 의미 유사 (보조) | 벡터 상위 k=5 (제목+첫 문장, 제목만 두 질의) | 확인 필요, 우선순위 낮음. 값 비교 안 함 |
| 재검사 | 바뀐 조 자체의 인용을 개정안 기준으로 다시 해석 | 새로 안 풀리면 깨짐, 없어지면 해소 |

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 번호 이동 시 같은 규정 안 인용은 깨짐, 다른 규정 인용은 확인 필요 | 내규관리규정 관행: 개정안 부칙의 「다른 내규와의 관계」가 다른 내규의 옛 인용을 새 인용으로 읽게 함. 같은 규정 안은 개정문에 직접 고쳐야 함 | 모두 깨짐 (부칙이 있는 경우 과잉) |
| 깨짐 사유에 "지금 제7조는 신설 조문을 가리킴"을 적음 | 번호 이동의 진짜 위험은 인용이 '없는 조'가 아니라 '다른 조'를 조용히 가리키는 것 (재검사로는 ok로 보임) | — |
| 값 비교는 같은 제목 후보에만 | 의미 유사 후보에 적용하니 취업규칙 제44조(육아기 근로시간 단축, 「2회」)를 새 충돌로 오경보 | 모든 후보 |
| 의미 유사 질의는 제목+첫 문장, 제목만 | 조 전체를 넣으면 호 목록 때문에 주제가 흐려져 「당연해직」(해외파견지침 제35조)을 못 찾음. 바꾼 뒤 상위 5 안 | 조 전체 한 질의 |
| 삭제된 조의 기존 인용 이슈는 해소로 세지 않음, 삭제된 조는 법령 대조 안 함 | 조가 없어져 함께 사라진 것은 해결이 아님 | — |
| 결과는 판정 아님: 충돌·해소는 양쪽 문안을 보여 주는 후보 | AGENTS §3 | 자동 판정 |

## 한계
- 법령 대조는 바뀐 조가 직접 인용한 법령만. S01(남녀고용평등법 육아휴직 분할 기준)처럼 인용 없이 같은 주제인 법령은 법률 DB의 주제 연결이 있어야 함 → 한석희 합의 항목
- 값 비교는 숫자+단위 토큰 비교라 단위가 다르거나(1년 vs 12개월) 문장으로 쓴 값(두 번)은 못 봄. `slot` 주제키 구현 시 대체
- 관련 조항 표의 대상이 조 단위라 항까지 좁혀 보지 못함 (확인 필요가 넓게 잡힘)
- S03 같은 큰 번호 이동은 확인 필요가 18건 → 묶음(원인 묶음ID)으로 보여 줄 필요
- 의미 유사 후보는 노이즈 많음 (S01 5건 중 직접 관련 0건). 우선순위 낮음으로 분리해 둠
