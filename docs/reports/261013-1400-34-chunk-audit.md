- 별표·별지 숫자 칸(배점 10, 70), 「제21조의 2(」 띄어쓰기, 원문 표기 「제12-5조」, 「2014.12.29.」를 호로 읽은 것, 삭제된 조
- 다른 내규 사이 같은 문장(복무규정·취업규칙 등 25건): 원문이 실제로 같음
- 색인 제외 223개: 부칙·별지·삭제는 설계상 제외. 본문 정상 청크 중 빠진 것 없음
- 항이 한 청크에 섞인 곳 0: 원문에서 붙어 있던 항(「…한다.② …」)도 가빈 쪽에서 잘 나뉨

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 점검은 `body`만 읽음 | 보정 칸(`body_search`·`cites` 등)을 보면 가빈이 이미 고친 것과 원래 결함이 섞임. 우리 점검 코드 원칙과 같음 (`safe_select`) | 보정 칸까지 대조 — 가빈 확인용으로는 나중에 |
| 원문 기준은 가빈 원문 텍스트 + 우리 파싱 둘 다 | 우리 파싱만 기준으로 하면 우리 파서 결함이 가빈 결함처럼 보임 (실제로 「제l조」는 둘 다 놓쳤음) | 우리 파싱만 |
| 자동 후보는 유형마다 실제 청크를 열어 판정 | 첫 실행 후보 2,958건 중 대부분이 정규식 오탐(표 숫자, 띄어쓰기 없는 호 등) | 자동 결과 그대로 전달 |
| 우리 파서 「제l조」는 바로 고침 | 우리 담당. 조 하나가 통째로 빠지는 결함 | 가빈과 같이 고치기 |
