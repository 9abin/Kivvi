독립 평가(가빈 corrections) **17/23 → 20/23** — 남은 3건은 모두 부칙 옛 조문(정책 차이). 전체 원장 40/46 → **43/46**, 우선순위 높음 30 → **38**. 정상 확인 10곳 오탐 0 유지.
