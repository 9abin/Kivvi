## 요약
한석희 법률 DB(`data/law_rag.sqlite3`, 법제처 현행법령 232개)를 읽기 전용으로 연결했다. 원본 JSON에 조문별 `조문변경여부`·`조문시행일자`·`조문이동`과 법령 `개정문`이 있어 **스냅샷 두 개 없이 "최근 개정에서 바뀐 법령 조문 × 그걸 인용하는 우리 조문"**을 만든다.
- 우리 규정의 법령 인용 399개 중 298개 법령 연결, 249개 조문까지 연결(조 못 찾음 0)
- 법령 개정 대조 22건 (예: 개인정보 보호법 2026.09.11 제23·31조, 성폭력처벌법 2026.10.02 제2조 정의, 남녀고용평등법 2026.09.18 제19조 육아휴직)
- 2026.07.01 이후 시행 개정이 우리 인용 조문에 닿는 법령 11종
- 변경안 점검에 "같은 제목 법령" 경로 추가 → **S01 법령 대조 0/1 → 1/1** (인사규정 제30조 육아휴직 ↔ 남녀고용평등법 제19조). 시나리오 3개 모든 분류 일치
- 정답 원장 합계 43/46 그대로, 결과 249 → 271, 담당 21건 확인 대기 26 → 36

## 신호
| 결과 종류 | 조건 | 우선순위 |
|---|---|---|
| 법령_개정확인 | 인용한 법령 조문이 최근 개정에서 바뀜(조문변경여부=Y), 시행일이 인용 쪽 마지막 개정보다 뒤 | 중간 (이동이면 높음) |
| 법령_조문없음 | 법령은 DB에 있는데 인용한 조가 없음 | 높음 (현재 0건) |
결과 설명에 해당 조를 고친 **개정문 문장**을 붙인다. 타법개정(다른 법 부칙으로 바뀜)은 개정문에서 이 법 부분만 잘라 낸다.

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 판정이 아니라 대조 요청 (중간) | 법령이 바뀌어도 규정을 고칠 필요가 없을 수 있음. 법적 판단 금지(AGENTS §3) | 높음으로 일괄 |
| 조문변경여부·개정문으로 최근 개정만 봄 | DB가 현행 한 시점이라 그 이전 개정 이력은 없음. 스냅샷 반입이 쌓이면 시행일 비교로 확장 | 스냅샷 2개 대기 |
| 약칭 사전(공공기록물법·특정금융정보법·청탁금지법 등) + 「약칭 + 시행령」 | 우리 표기로 못 찾던 법령 연결 (291 → 298) | 정식 명칭만 |
| 같은 제목 법령 조문을 변경안 점검의 법령 대조 후보로 | 바뀐 조가 법령을 직접 인용하지 않아도 같은 주제의 법정 기준과 대조 (S01) | 인용만 |
| 법률 DB가 없으면 건너뜀 | 파일은 git 제외, 팀원 PC마다 다를 수 있음 | 필수 의존 |
