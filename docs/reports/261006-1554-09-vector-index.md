## 요약
90건 본문을 항 단위 청크 4,449개로 만들어 BGE-m3로 임베딩했다(1024차원, GPU 23초). 벡터 원본(.npy)과 Chroma 색인을 같이 저장한다.
인용 문맥으로 인용 대상 규정 안을 검색해 "인용된 조가 상위에 없고 다른 조가 훨씬 가까운" 경우를 후보로 냈다.
1주차 의미 검사 대상 5건(C2·C5·C12·F2×2)은 **모두 후보**에 들었지만, 나머지 정상 인용 83개 중 20개도 걸려 **정밀도는 약 20%**다. 벡터는 후보 생성까지만 맡기고, 판단 보조는 다음 단계(LLM 비교)로 넘긴다.

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 청크 = 항(호·목 포함), 앞에 「규정명 > 제N조(제목)」 | 원본 기획 "항으로 검색, 조 전체 제공". 항 중앙 77자로 짧아 맥락 접두어 필요 | 조 단위(2,042), 항·호·목 각각(7,338) |
| 부칙·별지·삭제 조 제외 | 부칙은 옛 번호, 별지는 메타데이터로만 (02-specs) | 전부 포함 |
| 벡터 원본을 .npy로 따로 저장, 검색은 행렬곱 | 4,449×1024 규모라 충분. 저장소를 pgvector로 바꿔도 재계산 불필요 | Chroma만 |
| Chroma는 임시 저장소 | 엔진 합의(PostgreSQL+pgvector 권장) 전 | 바로 pgvector |
| 기본 모델 BGE-m3 | BGE-m3-ko와 비교: 정답 5건 탐지는 같고 오탐 22 vs 27 (자기 조 제외 전 기준) | BGE-m3-ko |
| 인용하는 조문 자신은 순위에서 제외 | 질의 문맥이 그 조문에서 나와 늘 1위가 됨. 제외 후 정상 인용 1위 비율 21% → 41% | 그대로 |
| 후보 기준: 인용된 조 순위 > 3 그리고 1위와 점수차 ≥ 0.05 | 정답 5건을 모두 포함하는 단순 기준. 조정 가능(인자) | 고정 임계값 |
