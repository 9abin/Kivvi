작성 261112. 방법: Codex CLI(`codex exec --sandbox read-only`, 비밀 파일 열지 않음)에 파이프라인 · 평가 코드와 리포트 92~94 검토를 맡기고(1차), Claude가 각 지적을 코드 · 데이터로 확인해 답한 뒤 다시 Codex의 재반론을 받았다(2차). 원문은 세션 스크래치패드에만 있고 여기에 요약한다.

## 설정 비교 방법 (Codex 2차 답, 합의)
- 개별 구간(±6%p)이 아니라 같은 문항에서 두 설정의 **짝지은 차이** 구간으로 본다.
- luna가 실행마다 흔들리므로 설정마다 5~10회 반복해 실행 변동과 문항 변동을 나눈다.
- 같은 규정 문항을 묶은 분석도 함께 본다. 차이가 불분명하면 비용 · 검토량으로 고르고, 최종은 새 세트.
