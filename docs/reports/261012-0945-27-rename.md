## 요약
명칭 변경표 하나로 90개 규정에서 출현 위치를 찾아 **규정별 개정문·대비표**를 한 번에 만든다. 2026.08.28 실제로 하루에 15개 규정 35개 항의 직책·조직 명칭을 손으로 바꾼 일이 근거다(옛 명칭은 원문에 없어 시연은 "다음 개편" 가정).
- 「부기관장→전무이사, 지역투자센터→지역성장센터」: 출현 39곳·규정 16개 → 자동 37곳(16개 규정 개정문, 적용 실패 0, 적용 후 남은 옛 명칭 0), 수작업 2(직무전결규정·직제지침 별표)
- 함정 시험 「상임이사→상근이사」: 출현 5곳 전부 「**비**상임이사」 → **자동 0, 확인 필요 5** (단순 바꾸기라면 5곳 모두 잘못 바뀜)

## 분류 규칙
| 분류 | 조건 | 처리 |
|---|---|---|
| 자동 | 명칭 앞이 한글이 아님 | 「제N조제M항 중 "A"를 "B"로 한다」, 조 제목은 「제N조의 제목 중 …」 |
| 확인 필요 | 명칭 앞이 한글(더 긴 낱말의 일부일 수 있음), 또는 그런 출현과 같은 항 | 낱말·문맥을 보여 주고 사람이 판단 (「중 "A"를」은 항 안의 A를 모두 바꾸므로 섞인 항은 자동 안 함) |
| 수작업 | 별표·별지·부칙 | 위치·문맥 목록 |

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| 앞 글자가 한글이면 자동으로 안 바꿈 | 「비상임이사」 같은 오치환 방지. 「경영기획본부장」처럼 정상인 경우도 확인 필요로 가지만 안전한 쪽 | 단순 바꾸기 |
| 규정별로 개정문을 만들고 적용·검증 | 실제 개편은 규정마다 소관 부서·개정 절차가 따로임. 적용기로 검증해 문장 오류 0 | 한 문서에 몰기 |
| 내규관리규정 제8조③이 있어도 문안 정비 | 「새 이름으로 읽는다」는 해석 규정일 뿐 문안 불일치는 남음 (2026.08.28에도 실제로 문안을 고침) | 정비 생략 |
