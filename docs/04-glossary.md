# 04. 용어집

## 규정 구조

| 용어 | 정의 | 비고 |
|---|---|---|
| 정관 | 회사 최상위 규범 | 위계 1 |
| 규정 | 정관 아래 규범 | 위계 2 |
| 지침 | 규정 아래 세부 운영 기준 | 위계 3 |
| 조·항·호·목 | 제N조 > ①항 > 1.호 > 가.목 | `제N조의M`처럼 가지 번호 있음 |
| 부칙 | 시행일·경과조치. 옛 조문 번호를 새 번호로 읽게 하는 조항이 있을 수 있음 | 임직원행동강령, 직제규정 |
| 별표 / 별지 | 별표: 표 형태 기준(금액·징계 기준 등) / 별지: 서식 | |

## 판정 규칙 (내규관리규정)

| 규칙 | 근거 |
|---|---|
| 법령·정관에 저촉되는 내규 부분은 효력 상실 | 제7조① |
| 규정 > 지침 | 제7조② |
| 같은 순위 내규 간, 같은 내규 조문 간 저촉 시 나중에 제정·개정된 쪽 우선 | 제7조③ |
| 부서·직위·기관명이 바뀌었는데 문서를 안 고쳤으면 새 이름으로 읽음 | 제8조③ |
| 1차 해석권한은 업무담당부서, 불분명·이견 시 내규담당부서 → 이 시스템의 판단은 참고 해석 | 제8조② |
| 개정 절차: 입안 → 내규담당부서·준법감시인 조정(법령등 저촉·중복 검토) → 대표이사 결재 또는 이사회 의결 → 등록·공지 → 시행 | 제20~24조 |

예외: 취업규칙 제3조 단서("하위 지침이 취업규칙보다 우선")는 위 규칙과 반대라 우선순위 판단에 쓰지 않는다 (X7).

## 점검 용어

| 용어 | 정의 |
|---|---|
| 명시 인용 | 조문에 "○○법 제N조"처럼 대상을 직접 적은 것 |
| 암묵 관련 | 인용 없이 같은 사항을 정한 것. 표시만 하고 판정하지 않음 |
| 반입 | 외부망에서 수집한 법령 변경분을 망간 자료전송으로 내부망 RDB에 적재하는 것 |
| 기준일 | 점검 시점. 법조문 버전(시행일~종료일) 판단 기준 |
| finding | 점검 결과 1건. 대상 조문, 오류 유형, 근거, 수정안, 상태 |
| 근거 소멸 | 의존하던 조문·제도가 삭제·폐지됐는데 남아 있는 조항. 부칙 경과조치와 구분 |
| 개념 관계 | 정의 조문이 정한 용어 간 관계. 예: 무기계약직 ⊃ 일반무기계약직, 공무직 (직제규정 제16조) |
