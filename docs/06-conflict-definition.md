# 06. 충돌(저촉) 검토 대상의 정의와 범용 가정

- 작성: 261106. 전문가 확인 전 초안. 이 문서의 정의와 가정은 **임시**이며, 확인되면 해당 가정만 갱신한다.
- 관련: [82 근거 감사](reports/261106-1100-82-evidence-audit.md), [81 시험](reports/261105-1500-81-leave-layer-test.md), 원문 근거 `내규관리규정` 제7·21조, 검토 원자료 `data/한국벤처투자_내부규정/검토결과_노션용.md`

## 1. 출처가 쓰는 말

| 출처 | 말 | 뜻 |
|---|---|---|
| 내규관리규정 제7조 | 저촉 | 법령·정관에 저촉 → 그 부분 효력 상실 / 규정 > 지침 / 같은 순위끼리는 후법 우선 |
| 내규관리규정 제21조 | 저촉 또는 중복 | 내규안 협의 대상. 저촉과 중복은 별개 |
| 근로기준법 제96조 | 어긋나서는 아니 된다 | 취업규칙 대 법령·단체협약 |
| 법이론(2차 자료) | 충돌 | 한 규범이 요구하는 행위를 다른 규범이 양립 불가능하게 함 |

## 2. 정의 (세 겹)

1. **검토 대상** — 시스템 탐지 범위. 두 조항(또는 조항과 법령)이 같은 사안을 다루는데 문면상 다르거나 참조가 맞지 않아 담당자 확인이 필요한 관계. 유형: 값·내용 차이(A), 중복(B), 오인용·명칭 불일치(C), 표기 오류(D).
2. **저촉 후보** — 검토 대상 중 아래 네 조건이 문면에서 모두 확인되는 것. 하나라도 확인되지 않으면 비충돌이 아니라 **UNKNOWN**.
   ① 같은 적용 대상 ② 같은 행위·사안 ③ 시점이 겹침 ④ 한쪽을 따르면 다른 쪽을 지킬 수 없음
3. **확인된 저촉** — 내규담당부서·준법감시인(법무)이 판단한 것. 효과는 제7조를 ①법령·정관 → ②규정·지침 → ③시간 순서로 적용.

정의하지 않는 것: 중복(제21조가 따로 둠), 오인용·표기 오류(정합성 문제), 업무상 개정 필요성, 법적 효력의 확정.

## 3. 범용 가정 (전문가 부재로 둔 것)

| # | 가정 | 근거 | 틀리면 | 전문가가 있으면 물을 것 |
|---|---|---|---|---|
| G1 | 비교하는 모든 문서는 현재 유효한 ALIO 공시본이고, 현행본끼리는 시점이 겹친다 | 공시 출처 | 경과조치·적용례가 있는 쌍에서 오탐 | 부칙 경과조치를 어디까지 반영해야 하나 |
| G2 | 조 제목·사안어가 같고 주체가 서로 배타적으로 명시되지 않았으면 같은 대상으로 본다. 주체가 다르게 명시되면 비충돌 | 일반 해석 관행 | 직원/임원 등 대상이 다른데 후보가 뜸(오탐) | 대상 구분의 기준 |
| G3 | 같은 사안의 한도·기한·횟수·비율 값이 다르면 동시 준수가 어렵다고 보고 후보로 올린다 (과소탐지 방지) | 보수적 원칙 | 의도된 차이도 후보가 됨(오탐 증가) | 어떤 차이가 의도된 차이인가 |
| G4 | 법령 문구가 「~할 수 있다」 꼴의 사용 한도(권리 보장)이면 최저 기준으로 보고, 내규가 더 적게 정하면 저촉 가능, 더 많게 정하면 허용 | 근로기준법 제97조의 취지(기준 미달 무효) | 상한형·의무형 규정에 잘못 적용 | 방향 판별 기준 |
| G5 | 위계는 법령 > 정관 > 규정(취업규칙 포함) > 지침 | 내규관리규정 제2·7조 | 이름 끝말로 종류를 잘못 판별 | 종류가 불분명한 내규의 지위 |
| G6 | 선후는 문서 단위 최종 개정일로 본다 | 조문 단위 이력 파싱 미구현 | 조문이 더 오래된 경우 오판 | 조문 단위 개정일 확인 |
| G7 | 「다만」 단서·준용·위임 문구가 있으면 예외 가능성으로 UNKNOWN 처리 | 일반 해석 관행 | 예외가 아닌데 보류됨 | 예외와 위임의 효력 |
| G8 | 불확실하면 비충돌로 처리하지 않고 UNKNOWN으로 남긴다 | 후보를 숨기지 않는 원칙(docs/05 §3) | 후보 수 증가 | 보류 건의 처리 기한 |
| G9 | 시스템은 저촉을 확정하지 않는다. 법적 효력·개정 필요성은 판정하지 않는다 | docs/05 §3 | | |
| G10 | 규칙·AI가 낸 판정은 전문가 확인 전 임시이며 정밀도·재현율을 주장하지 않는다 | 현업 확인 0건 | | |

## 4. 21건 검토 결과를 이 정의로 다시 분류 (원자료 A~D, 44건)

| 분류 | 건수 | 정의상 위치 |
|---|---|---|
| A 내용 충돌 | 5 | A1~A4 저촉 후보(아래 표), A5 용어 정합성 |
| B 중복 | 8 | 중복 (저촉 아님). 값이 다르면 A로 올라감(B3 → A4, B4 → A1) |
| C 오인용·명칭 | 24 | 정합성 |
| D 표기 오류 | 7 | 정합성 |

A의 네 조건 점검(문면 기준, G1~G8 적용):

| # | 대상 | 행위 | 시점 | 양립 불가 | 제7조 적용(제안) |
|---|---|---|---|---|---|
| A1 육아휴직 분할 횟수(취업규칙 3회 ↔ 인사규정 2회) | 확인(직원) | 확인 | 확인(현행) | 확인(허용 횟수 3 대 2) | ① 남녀고용평등법 제19조의4 3회 → 인사규정이 법보다 적음 → 저촉 가능(G4) |
| A2 예산 전용 승인권자(회계규정 ↔ 이사회규정) | 확인 | 확인 | 확인 | 확인(대표이사 대 이사회) | ② 같은 순위(규정) → ③ 개정일. 정관 제36조⑦과의 관계는 UNKNOWN |
| A3 임원 퇴직금성 지급 결정기관(퇴직금지급규정 ↔ 정관) | UNKNOWN(특별공로금이 정관상 퇴직금 범위인가) | 확인 | 확인 | 확인(이사회 대 주주총회) | ① 정관 우선 가능 |
| A4 기피 의결 정족수(징계지침 ↔ 인사규정) | 확인 | 확인 | 확인 | 확인(2/3 대 과반수) | ② 규정(인사규정) 우선 |
| A5 별표4 「해임」 용어(징계지침 동일 문서) | — | — | — | 양립 불가 아님 | 정합성(용어 불일치) |

- 저촉 후보 4건, 이 중 1건은 대상 조건이 UNKNOWN. 전체 44건 중 약 9%.
- 시스템이 지금 낸 후보(DL-01 · DEF-01 · COUNT-01 21건)는 이 정의로는 대부분 **문면 차이(1단계)**이며, 네 조건 점검을 통과한 것만 저촉 후보로 올린다.

## 5. 다음 작업

- 규칙 후보 화면에 네 조건 점검(확인·UNKNOWN)과 제7조 단계 적용을 붙인다 (지금은 COUNT-01만).
- 「권한·의결·승인권자 차이」는 AUTH-01(승인·의결 주체 차이)을 261106에 추가했다. A2(회계규정 ↔ 이사회규정)와 A3(퇴직금지급규정 ↔ 정관)을 탐지하고(5쌍 중 2쌍, 나머지 3쌍은 사안이 달라 보임), A4(기피 의결 정족수)는 놓친다. 정족수 규칙 QUORUM-01은 시험 결과 의미 있는 후보가 없어 사용 안 함으로 둔다 (소집 요구 · 서면 의결 · 정관 변경 특례를 섞어 6쌍이 나옴).
- 전문가가 생기면 G1~G8을 위 표의 질문으로 하나씩 확인해 가정을 갱신한다.
