# 답변 설계 (④ 단계)

검색된 근거로 질문에 답하는 단계를 정리한다.
근거를 찾는 과정은 `검색_설계.md`, 화면과 실행 방법은 아래 6절을 본다.

**기준일: 2026.10.06**
**상태: 1차 구현 완료, 검증 전**

---

## 1. 흐름

```
질문 → Searcher.search() → Searcher.assemble() → 근거 번호 부여 → OpenAI 모델 → 인용 검사 → 답변
```

- `src/answer/pipeline.py`의 `Assistant.ask()`가 전체를 묶습니다.
- 근거가 0개면 모델을 부르지 않고 고정 문구로 답합니다.

---

## 2. 모델

| 항목 | 값 |
|---|---|
| 모델 | `gpt-4o-mini` (`config.py`의 `OPENAI_MODEL`) |
| API | OpenAI Responses API (`client.responses.create`) |
| 키 | 프로젝트 상위 폴더의 `.env` (`OPENAI_API_KEY`). Git에서 무시됨 |

모델을 바꾸려면 `OPENAI_MODEL`만 고칩니다. 이전에는 `gpt-5.1`로 확인했고, 품질 비교는 골든셋 이후입니다.

---

## 3. 근거 형식

모델에는 근거를 번호와 함께 넘깁니다.

```
[1] 급여규정 제17조 제1항 | 조문상태: 현행 | 개정: 2025년도 ...
(본문)
정정안내: ... (있을 때만)
```

- 번호는 답변의 `[n]` 인용과 같습니다.
- 근거 순서는 검색 결과(정확 조회 → 검색) → 인용 대상 → 형제 항입니다. 세부 규칙은 `검색_설계.md` 0.3절을 봅니다.

---

## 4. 답변 규칙

시스템 지시(`SYSTEM_PROMPT`)로 요청한 규칙입니다.

| 규칙 | 내용 | 강제 여부 |
|---|---|---|
| 근거 한정 | 제공된 근거에 있는 내용만 쓴다 | 지시만 (보장 안 됨) |
| 없음 | 근거가 질문에 답하지 못하면 "제공된 규정에서 확인되지 않습니다"라고 쓰고 담당 부서 확인을 안내한다 | 지시만. 검사 코드 없음 |
| 인용 | 문장마다 `[n]`을 붙인다 | 인용 번호 검사만 함 |
| 부칙 | "현행 기준이 아님"으로 밝힌다 | 지시만 |
| 삭제 | "삭제된 조항입니다"로 밝히고, 현행 기준으로 말하지 않는다 | 지시만 |
| 정정안내 | 근거에 있으면 답변 끝에 "※ 정정 안내"로 붙인다 | 지시만 |
| 충돌 | 근거끼리 다르면 둘 다 보여주고 판정하지 않는다 | 지시만. 판정 로직 없음 |
| 외부 법령 | 근거가 아니다 | 지시만 |

### 4.1 자동으로 검사하는 것
- 답변이 근거 범위 밖의 번호(`[9]`처럼 없는 번호)를 쓰면 경고합니다.
- 답변에 인용이 하나도 없는데 "확인되지 않습니다"도 없으면 경고합니다.

### 4.2 아직 없는 것
- **없음 판정**: 검색 점수 기준선으로 근거가 없는지 미리 판단하고, 모델을 부르지 않는 기능. 기준선은 골든셋의 "답 없는 질문"으로 정합니다.
- **충돌 판정**: 근거끼리 충돌하는지 찾고, 기준(위계 우선, 개정일 우선)으로 정리하는 기능. 기준은 사용자가 정해야 합니다.
- **인용 내용 검사**: 답변 문장이 인용한 조문의 내용과 맞는지 확인하는 기능.

---

## 5. 미정 항목

| 항목 | 상태 |
|---|---|
| 없음 기준선 (리랭커 점수) | 골든셋의 "답 없는 질문"으로 정함 |
| 충돌 판정 기준 (위계 우선, 개정일 우선) | 사용자 결정 필요 |
| 시간 초과, 재시도, 오류 처리 | 미구현 |
| 모델 품질 비교 (gpt-4o-mini vs gpt-5.1 등) | 골든셋 이후 |

---

## 6. 실행

```
cd rag_pipeline
uv run python -m src.answer.pipeline "질문"                              # 콘솔에서 한 번 질문
uv run streamlit run app/streamlit_app.py --server.address localhost    # 화면
```

화면 주소: `http://localhost:8501`
