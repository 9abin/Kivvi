# 실제 온톨로지 데이터베이스

`ontology.db`는 SQL 정의만 있는 빈 파일이 아니라 사용자의 온톨로지 구조와 실제 연결 데이터를 포함한 SQLite DB다. `schema.sql`은 이 DB의 구조를 설명하는 별도 파일이다.

통합본에는 개념 44개, 항·호–개념 연결 1,997개, 연결 속성 2,533개, 상위 항 연결 516개, 규칙값 2,466개가 저장되어 있다. 사용자 휴직 원본 DB와 대조해 아래 원본 행이 모두 값 변경 없이 포함된 것을 확인했다.

| 원본 테이블 | 원본 행 수 | 통합본에 동일하게 보존 |
|---|---:|---:|
| concept | 6 | 6 |
| concept_attr | 38 | 38 |
| concept_primary | 7 | 7 |
| edge_item_concept | 151 | 151 |
| edge_attr | 148 | 148 |
| edge_head | 38 | 38 |
| change_log | 46 | 46 |

대조 결과는 `../validation/user-schema-preservation.json`에 기록했다. 추가된 개념·연결은 AI 검토 확장분도 포함하며, 사용자 원본과 같은 확정 상태라고 해석하면 안 된다.

도메인 키는 `concept.parent`의 최상위 개념에서 검색 코드가 계산한다. 현재 SQLite에 `domain_key`라는 물리 컬럼을 새로 추가한 버전은 아니다. 원문·개념·연결·속성·출처 매핑은 실제 DB에 저장되어 있다.
